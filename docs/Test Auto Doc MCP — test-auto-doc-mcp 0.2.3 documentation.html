    Test Auto Doc MCP¶


    MCP server providing access to UTE TAF Knowledge Base documentation via vector search and structured API.

    This server exposes UTE TAF documentation tools through the Model Context Protocol (MCP), making them accessible to MCP-compatible clients like Cursor, Claude Desktop, and other AI assistants.

    Installation Guide¶

    Prerequisites¶

    • Python 3.10 or newer

    • Access to the Knowledge Base API endpoint (default: https://ute-knowledge-provider.ext.net.nokia.com)

    UTE TAF Package Installation (Artifactory)¶

    The package is stored in Artifactory. Before installing, configure your environment to resolve packages from Artifactory. See the TAF package installation guide for detailed Artifactory setup instructions.

    Install for Local MCP Client Use (recommended)¶

    When using the server with a local MCP client such as Cursor, install via pipx. This makes the test-auto-doc command globally available in your PATH inside an isolated environment — which is required for the MCP client to launch the server process automatically.

    pipx install test-auto-doc-mcp

    If you do not have pipx installed:

    pip install pipx
pipx ensurepath

    Install for Server / Development Use¶

    For running the server in a container, CI, or a virtualenv where you manage the environment directly, use pip:

    pip install test-auto-doc-mcp

    Install from Source¶

    pip install -e .

    Verify Installation¶

    Check that the CLI entrypoint is available:

    test-auto-doc --help

    Minimal Local Run¶

    Start the server with the default stdio transport:

    test-auto-doc

    For transport-specific client configuration examples, see the Examples section.

    Setup in Cursor¶

    Add the server to your Cursor MCP configuration (~/.cursor/mcp.json):

    {
  "mcpServers": {
    "test-auto-doc": {
      "command": "test-auto-doc"
    }
  }
}

    Cursor will launch the server process automatically.

    TAF package installation

    This document presents basic guide regarding TAF package installation. Detailed information about each project can be found in TAF documentation portal.

    Pip configuration

    In order to download a TAF library, user needs to point to certain Python package index. TAF uses Artifactory for storing Python packages.

    Warning

    Anonymous access to Artifactory has been removed. You must authenticate with your username and an identity token in order to download packages. See Anonymous access removal for details.

    Configuring pip client via Set Me Up

    To generate your pip configuration in Artifactory:

    1. Log in to Artifactory and open User Profile (top-right corner).
    2. Click Set Me Up.
    3. Select pypi package type.
    4. Change client to pip and select your repository.
    5. Generate the configuration and follow instructions.

    Ensure that your test environment uses proper index URL (which can be configured globally in pip.conf file or passed to pip via -i flag):

    • pip.conf file located under $HOME/.pip/pip.conf (Linux based OS):
    • Package installation command: pip install PACKAGE_NAME -i https://<username>:<token>@artifactory-espoo2.int.net.nokia.com/artifactory/api/pypi/ute-pypi-virtual/simple

    A pip.conf file should look as follows:

    [global]
index-url = https://<username>:<token>@artifactory-espoo2.int.net.nokia.com/artifactory/api/pypi/ute-pypi-virtual/simple

    Note

    Please keep in mind that there are also virtual instances of Artifactory targeted at some other Nokia sites. Depending on your location, using them can significantly improve package download speed:

    • Bangalore - https://artifactory-blr1.int.net.nokia.com/artifactory/api/pypi/ute-pypi-virtual/simple
    • Hangzhou - https://artifactory-hz1.int.net.nokia.com/artifactory/api/pypi/ute-pypi-virtual/simple
    • Franklin Park - https://artifactory-fpark1.int.net.nokia.com/artifactory/api/pypi/ute-pypi-virtual/simple

    Using virtual environment

    In order not to affect the main OS globally, you should install TAF packages in an isolated environment. This can be achieved using venv built-in Python module:

    python3.9 -m venv my_venv
source my_venv/bin/activate

    After activating a virtual environment, you can safely install and work with a certain Python library without worrying that global Python environment gets affected.

    In order to use the global Python interpreter again, virtual environment needs to be deactivated (using deactivate command).

    Note

    If you are a UTE test line user, then most probably you can take advantage of pyenv. Pyenv utility is present in the OS to create a virtual environment. Use pyenv virtualenv <PYTHON_VERSION> <VENV_NAME>, where:

    • PYTHON_VERSION stands for version of Python installed in OS
    • it can be verified by pyenv versions command
    • VENV_NAME stands for virtual environment name used later on for activation

    Example for Python 3.9.14:

    pyenv virtualenv 3.9.14 test_venv
pyenv activate test_venv
...
pyenv deactivate

    Installation

    Package can be simply installed via pip install PACKAGE_NAME command, for example:

    pip install taf.transport.ssh

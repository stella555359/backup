    MCP Tools Reference¶

    This section documents all MCP tools exposed by the TAF Documentation MCP Server. All documentation is auto-generated from Python docstrings in server.py.

    Utility Tools¶

    General utility tools.

    <use case>Uses semantic search over TAF documentation to retrieve information about Python libraries used for base station product automation (SBTS, VRAN, UE AUTOMATION, measurement equipment automation and all other activities where access to APIs or specific devices are needed).</use case> <instructions>Provide a specific natural-language query about TAF functionality and optionally specify the number of results to return. Semantic search returns the most relevant documentation sections, ordered by relevance.</instructions>

    Input Schema

    "query": {
      "type": "string"

      "type": "integer"

    "query"
  ]
}

  "description": "Tool response",

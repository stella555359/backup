## 题 1：进程与程序的区别

某系统中，一个可执行文件被用户连续启动了 3 次，则操作系统中通常会产生多少个进程？

A. 1 个  
B. 2 个  
C. 3 个  
D. 不确定，一定小于 3 个

**答案：C**

**解题思路：**

程序是静态的指令集合，进程是程序的一次执行过程。同一个程序可以被多次执行，每次执行都可以形成一个独立进程。因此连续启动 3 次，通常产生 3 个进程。

**易错点：**

不要把“一个程序文件”理解成“只能有一个进程”。程序是静态文件，进程是动态执行实例。

## 题 2：进程状态转换

某进程正在执行时，需要等待磁盘 I/O 完成。此时该进程的状态变化通常是：

A. 运行态 → 就绪态  
B. 运行态 → 阻塞态  
C. 阻塞态 → 运行态  
D. 就绪态 → 阻塞态

**答案：B**

**解题思路：**

运行中的进程如果需要等待某个事件，例如 I/O 完成、等待资源、等待信号，就不能继续占用 CPU，会进入阻塞态。

常见状态转换：

```text
就绪态 --被调度--> 运行态
运行态 --时间片到/被抢占--> 就绪态
运行态 --等待事件--> 阻塞态
阻塞态 --事件完成--> 就绪态
```

**易错点：**

阻塞态不能直接进入运行态，必须先回到就绪态，等待调度程序分配 CPU。

## 题 3：PCB 的作用

操作系统用来描述和管理进程的数据结构是：

A. 文件控制块 FCB  
B. 进程控制块 PCB  
C. 作业控制块 JCB  
D. 设备控制块 DCB

**答案：B**

**解题思路：**

PCB，即 Process Control Block，保存进程标识、进程状态、程序计数器、寄存器内容、调度信息、资源清单等信息。操作系统通过 PCB 感知和管理进程。

**易错点：**

PCB 是进程存在的唯一标志。没有 PCB，操作系统就无法管理该进程。

## 题 4：先来先服务调度 FCFS

有 3 个作业同时到达，运行时间分别为：

| 作业 | 运行时间 |
|---|---:|
| J1 | 4 |
| J2 | 3 |
| J3 | 2 |

若采用先来先服务算法，执行顺序为 J1、J2、J3，则平均周转时间是多少？

A. 4  
B. 5  
C. 6  
D. 7

**答案：C**

**解题思路：**

因为三个作业同时到达，所以：

```text
J1 完成时间 = 4
J2 完成时间 = 4 + 3 = 7
J3 完成时间 = 4 + 3 + 2 = 9
```

周转时间 = 完成时间 - 到达时间。到达时间都为 0，所以：

```text
J1 周转时间 = 4
J2 周转时间 = 7
J3 周转时间 = 9
平均周转时间 = (4 + 7 + 9) / 3 = 20 / 3 ≈ 6.67
```

如果选项按整数近似，选 D 更接近；如果题目要求精确值，则为 `20/3`。本题常见变体会把选项设为 `20/3`。

**易错点：**

计算周转时间时不要只看单个运行时间，要看从到达到完成经历的总时间。

## 题 5：短作业优先调度 SJF

有 3 个作业同时到达，运行时间分别为：

| 作业 | 运行时间 |
|---|---:|
| A | 8 |
| B | 4 |
| C | 2 |

若采用非抢占式短作业优先调度，则执行顺序是：

A. A、B、C  
B. C、B、A  
C. B、C、A  
D. A、C、B

**答案：B**

**解题思路：**

短作业优先 SJF 会优先选择估计运行时间最短的作业。三个作业同时到达时，按运行时间从小到大排序：

```text
C(2) -> B(4) -> A(8)
```

**易错点：**

SJF 能降低平均等待时间，但可能导致长作业长期等待，也就是“饥饿”。

## 题 6：PV 操作基础

设有一个互斥信号量 `mutex`，用于控制某临界资源的访问。若该资源一次只允许一个进程访问，则 `mutex` 的初值应为：

A. 0  
B. 1  
C. -1  
D. 资源请求进程数

**答案：B**

**解题思路：**

互斥信号量用于保证同一时刻只有一个进程进入临界区。资源初始可用，所以信号量初值为 1。

```text
P(mutex)  // 进入临界区前申请资源
访问临界资源
V(mutex)  // 离开临界区后释放资源
```

**易错点：**

互斥信号量通常初值为 `1`；资源信号量初值通常为资源数量。

## 题 7：生产者-消费者问题

某系统有一个容量为 `n` 的缓冲区，生产者向缓冲区放产品，消费者从缓冲区取产品。为实现同步与互斥，通常需要设置的信号量为：

A. 只需要 `mutex`  
B. 只需要 `empty` 和 `full`  
C. `mutex`、`empty`、`full`  
D. 只需要一个计数器

**答案：C**

**解题思路：**

生产者-消费者问题既需要互斥，也需要同步。

```text
mutex = 1   // 保证对缓冲区的互斥访问
empty = n   // 空缓冲区数量
full = 0    // 满缓冲区数量
```

生产者：

```text
P(empty)
P(mutex)
放入产品
V(mutex)
V(full)
```

消费者：

```text
P(full)
P(mutex)
取出产品
V(mutex)
V(empty)
```

**易错点：**

`P(empty)` 必须在生产者放产品之前执行，否则缓冲区满时仍可能继续放入。  
`P(full)` 必须在消费者取产品之前执行，否则缓冲区空时仍可能继续取出。

## 题 8：死锁必要条件

以下哪一项不是死锁产生的必要条件？

A. 互斥条件  
B. 请求并保持条件  
C. 可剥夺条件  
D. 循环等待条件

**答案：C**

**解题思路：**

死锁产生有四个必要条件：

1. 互斥条件
2. 请求并保持条件
3. 不可剥夺条件
4. 循环等待条件

题目问“不是必要条件”，所以选择“可剥夺条件”。真正的必要条件是“不可剥夺条件”。

**易错点：**

看清楚题干是否有“不是”“不属于”“错误的是”等否定词。

## 题 9：银行家算法安全序列

某系统有 3 类资源 A、B、C，当前可用资源向量为：

```text
Available = (3, 3, 2)
```

各进程的最大需求 Max 和已分配 Allocation 如下：

| 进程 | Max | Allocation |
|---|---|---|
| P1 | (7, 5, 3) | (0, 1, 0) |
| P2 | (3, 2, 2) | (2, 0, 0) |
| P3 | (9, 0, 2) | (3, 0, 2) |
| P4 | (2, 2, 2) | (2, 1, 1) |
| P5 | (4, 3, 3) | (0, 0, 2) |

系统是否处于安全状态？

**答案：处于安全状态。一个安全序列为 P2、P4、P5、P1、P3。**

**解题思路：**

先计算：

```text
Need = Max - Allocation
```

| 进程 | Need |
|---|---|
| P1 | (7, 4, 3) |
| P2 | (1, 2, 2) |
| P3 | (6, 0, 0) |
| P4 | (0, 1, 1) |
| P5 | (4, 3, 1) |

从 `Available = (3, 3, 2)` 开始：

```text
P2 Need (1,2,2) <= Available (3,3,2)
执行 P2 后释放 Allocation (2,0,0)
Available = (5,3,2)

P4 Need (0,1,1) <= Available (5,3,2)
执行 P4 后释放 Allocation (2,1,1)
Available = (7,4,3)

P5 Need (4,3,1) <= Available (7,4,3)
执行 P5 后释放 Allocation (0,0,2)
Available = (7,4,5)

P1 Need (7,4,3) <= Available (7,4,5)
执行 P1 后释放 Allocation (0,1,0)
Available = (7,5,5)

P3 Need (6,0,0) <= Available (7,5,5)
执行 P3 后释放 Allocation (3,0,2)
Available = (10,5,7)
```

所有进程都能完成，因此系统处于安全状态。

**易错点：**

银行家算法判断的是“是否安全”，不是“是否已经死锁”。能找到安全序列，说明系统安全。

## 题 10：资源分配与死锁判断

系统中有 4 个同类资源，进程 P1、P2、P3 分别已经占有 1、1、2 个资源，并且每个进程还都需要再申请 1 个资源才能完成。此时系统是否可能发生死锁？

A. 一定不会死锁  
B. 可能发生死锁  
C. 已经发生死锁  
D. 无法判断

**答案：C**

**解题思路：**

系统共有 4 个资源，当前分配情况：

```text
P1 占有 1
P2 占有 1
P3 占有 2
已分配资源总数 = 1 + 1 + 2 = 4
可用资源数 = 0
```

每个进程还需要 1 个资源才能完成，但系统已经没有可用资源。三个进程都保持已有资源并等待新的资源，无法继续执行，形成死锁。

**易错点：**

如果存在至少一个进程能够获得足够资源并完成，它完成后可以释放资源，系统可能不死锁。本题没有任何可用资源，且每个进程都还差 1 个资源，所以已经死锁。

## 总结记忆

```text
进程 = 程序的一次执行过程
PCB = 进程存在的唯一标志
线程 = CPU 调度基本单位
进程 = 资源分配基本单位

运行态等待 I/O -> 阻塞态
时间片用完 -> 就绪态
阻塞事件完成 -> 就绪态

互斥信号量初值 = 1
资源信号量初值 = 资源数量
Need = Max - Allocation
```

## 做题顺序建议

1. 遇到状态转换题，先判断进程为什么离开当前状态：被调度、时间片到、等待事件、事件完成。
2. 遇到调度题，先画时间轴，再算完成时间、周转时间、带权周转时间。
3. 遇到 PV 操作题，先区分互斥关系和同步关系。
4. 遇到死锁题，先检查四个必要条件，再看是否存在可完成进程。
5. 遇到银行家算法题，先算 `Need`，再反复寻找 `Need <= Available` 的进程。

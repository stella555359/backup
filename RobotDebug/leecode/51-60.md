## 51. 岛屿数量（Number of Islands，LC 200，Medium）

**题意**：`'1'` 为陆地、`'0'` 为水，求四连通的岛屿个数。

**考点**：网格 DFS/BFS 连通块；原地标记已访问避免额外空间。

**思路**：遍历网格，遇到 `'1'` 计数加一并 DFS 把整片陆地淹没（置 `'0'`）。

```python
def numIslands(grid: list[list[str]]) -> int:
    if not grid:
        return 0
    m, n = len(grid), len(grid[0])
    def sink(i, j):
        if 0 <= i < m and 0 <= j < n and grid[i][j] == '1':
            grid[i][j] = '0'
            sink(i + 1, j)
            sink(i - 1, j)
            sink(i, j + 1)
            sink(i, j - 1)
    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                count += 1
                sink(i, j)
    return count
```

**复杂度**：时间 O(m·n)，空间 O(m·n)（递归栈最坏）。

**最 Pythonic 写法**：用方向元组 + 循环替代四次显式递归调用，`sink` 主体更紧凑。

```python
def numIslands(grid: list[list[str]]) -> int:
    if not grid:
        return 0
    m, n = len(grid), len(grid[0])
    def sink(i, j):
        if 0 <= i < m and 0 <= j < n and grid[i][j] == '1':
            grid[i][j] = '0'
            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                sink(i + di, j + dj)
    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                sink(i, j)
                count += 1
    return count
```

## 52. 腐烂的橘子（Rotting Oranges，LC 994，Medium）

**题意**：`2` 为腐烂橘子，每分钟向四邻新鲜橘子（`1`）扩散，求全部腐烂所需分钟，无法则返回 -1。

**考点**：多源 BFS；按层计时；最后检查是否仍有新鲜橘子。

**思路**：所有腐烂橘子入队作为第 0 层，逐层扩散计时，结束后若仍有新鲜橘子返回 -1。

```python
from collections import deque

def orangesRotting(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    q = deque()
    fresh = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == 2:
                q.append((i, j))
            elif grid[i][j] == 1:
                fresh += 1
    minutes = 0
    while q and fresh:
        minutes += 1
        for _ in range(len(q)):
            i, j = q.popleft()
            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                    grid[ni][nj] = 2
                    fresh -= 1
                    q.append((ni, nj))
    return -1 if fresh else minutes
```

**复杂度**：时间 O(m·n)，空间 O(m·n)。

**最 Pythonic 写法**：用生成器推导初始化队列，`sum(row.count(1) ...)` 一行数出新鲜橘子。

```python
from collections import deque

def orangesRotting(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    q = deque((i, j) for i in range(m) for j in range(n) if grid[i][j] == 2)
    fresh = sum(row.count(1) for row in grid)
    minutes = 0
    while q and fresh:
        minutes += 1
        for _ in range(len(q)):
            i, j = q.popleft()
            for ni, nj in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                    grid[ni][nj] = 2
                    fresh -= 1
                    q.append((ni, nj))
    return -1 if fresh else minutes
```

## 53. 课程表（Course Schedule，LC 207，Medium）

**题意**：给定先修关系，判断能否修完所有课程（即有向图是否无环）。

**考点**：拓扑排序（Kahn BFS 入度法 / DFS 三色法）。

**思路**：建图统计入度，入度为 0 的入队，逐个「上课」并削减后继入度，最终修完数等于课程数则无环。

```python
from collections import deque

def canFinish(numCourses: int, prerequisites: list[list[int]]) -> bool:
    graph = [[] for _ in range(numCourses)]
    indeg = [0] * numCourses
    for cur, pre in prerequisites:
        graph[pre].append(cur)
        indeg[cur] += 1
    q = deque(i for i in range(numCourses) if indeg[i] == 0)
    done = 0
    while q:
        node = q.popleft()
        done += 1
        for nxt in graph[node]:
            indeg[nxt] -= 1
            if indeg[nxt] == 0:
                q.append(nxt)
    return done == numCourses
```

**复杂度**：时间 O(V + E)，空间 O(V + E)。

**最 Pythonic 写法**：直接用标准库 `graphlib.TopologicalSorter`（Python 3.9+），`prepare()` 有环则抛 `CycleError`。

```python
from graphlib import TopologicalSorter, CycleError

def canFinish(numCourses: int, prerequisites: list[list[int]]) -> bool:
    ts = TopologicalSorter({i: [] for i in range(numCourses)})
    for cur, pre in prerequisites:
        ts.add(cur, pre)
    try:
        ts.prepare()
        return True
    except CycleError:
        return False
```

## 54. 实现 Trie（前缀树，LC 208，Medium）

**题意**：实现支持 `insert`、`search`、`startsWith` 的前缀树。

**考点**：字典树结构；用 `children` 字典 + 结束标记。

**思路**：每个节点维护子节点字典与「是否为单词结尾」标记，按字符逐层下探。

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word: str) -> None:
        node = self
        for ch in word:
            node = node.children.setdefault(ch, Trie())
        node.is_end = True

    def _find(self, prefix: str) -> 'Trie':
        node = self
        for ch in prefix:
            if ch not in node.children:
                return None
            node = node.children[ch]
        return node

    def search(self, word: str) -> bool:
        node = self._find(word)
        return node is not None and node.is_end

    def startsWith(self, prefix: str) -> bool:
        return self._find(prefix) is not None
```

**复杂度**：每次操作 O(L)，L 为单词长度。

**最 Pythonic 写法**：用「自引用的 `defaultdict`」当字典树，插入时自动建层，用哨兵对象作结束标记。

```python
from collections import defaultdict

END = object()                 # 结束标记

def _trie():
    return defaultdict(_trie)

class Trie:
    def __init__(self):
        self.root = _trie()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            node = node[ch]
        node[END] = True

    def search(self, word: str) -> bool:
        node = self.root
        for ch in word:
            if ch not in node:
                return False
            node = node[ch]
        return END in node

    def startsWith(self, prefix: str) -> bool:
        node = self.root
        for ch in prefix:
            if ch not in node:
                return False
            node = node[ch]
        return True
```

## 55. 全排列（Permutations，LC 46，Medium）

**题意**：返回不含重复数字数组的所有排列。

**考点**：回溯模板；用 `used` 标记或交换法。

**思路**：维护路径与已用标记，逐位选择未用元素，满则记录并回溯。

```python
def permute(nums: list[int]) -> list[list[int]]:
    res = []
    used = [False] * len(nums)
    path = []
    def backtrack():
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i, x in enumerate(nums):
            if used[i]:
                continue
            used[i] = True
            path.append(x)
            backtrack()
            path.pop()           # 回溯
            used[i] = False
    backtrack()
    return res
```

**复杂度**：时间 O(n·n!)，空间 O(n)。

**最 Pythonic 写法**：直接用 `itertools.permutations`，一行生成全部排列。

```python
from itertools import permutations

def permute(nums: list[int]) -> list[list[int]]:
    return [list(p) for p in permutations(nums)]
```

## 56. 子集（Subsets，LC 78，Medium）

**题意**：返回数组所有子集（幂集），元素互不相同。

**考点**：回溯（选/不选）或迭代「逐个扩展」；位运算枚举也可。

**思路**：从每个起点出发，把当前路径加入结果，再向后扩展。

```python
def subsets(nums: list[int]) -> list[list[int]]:
    res = []
    path = []
    def backtrack(start):
        res.append(path[:])           # 每个节点都是一个子集
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1)
            path.pop()
    backtrack(0)
    return res
```

**复杂度**：时间 O(n·2ⁿ)，空间 O(n)。

**最 Pythonic 写法**：枚举所有长度，用 `itertools.combinations` 生成每个子集。

```python
from itertools import combinations

def subsets(nums: list[int]) -> list[list[int]]:
    return [list(c) for r in range(len(nums) + 1) for c in combinations(nums, r)]
```

## 57. 电话号码的字母组合（Letter Combinations，LC 17，Medium）

**题意**：给定数字串（2-9），返回所有可能的字母组合。

**考点**：映射表 + 回溯；空输入特判。

**思路**：按数字依次取候选字母回溯拼接。

```python
def letterCombinations(digits: str) -> list[str]:
    if not digits:
        return []
    mapping = {'2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
               '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'}
    res = []
    path = []
    def backtrack(i):
        if i == len(digits):
            res.append(''.join(path))
            return
        for ch in mapping[digits[i]]:
            path.append(ch)
            backtrack(i + 1)
            path.pop()
    backtrack(0)
    return res
```

**复杂度**：时间 O(4ⁿ·n)，空间 O(n)。

**最 Pythonic 写法**：用 `itertools.product` 对各数字的候选字母做笛卡尔积，一行拼出所有组合。

```python
from itertools import product

def letterCombinations(digits: str) -> list[str]:
    if not digits:
        return []
    mapping = {'2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
               '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'}
    return [''.join(p) for p in product(*(mapping[d] for d in digits))]
```

## 58. 组合总和（Combination Sum，LC 39，Medium）

**题意**：候选数可重复使用，返回所有和为 `target` 的组合（无重复组合）。

**考点**：回溯中「从 `start` 而非 0 开始」避免重复组合；可重复用同一元素故传 `i`。

**思路**：排序后回溯，剩余值小于候选即剪枝；允许重复使用故递归传 `i`。

```python
def combinationSum(candidates: list[int], target: int) -> list[list[int]]:
    candidates.sort()
    res = []
    path = []
    def backtrack(start, remain):
        if remain == 0:
            res.append(path[:])
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remain:
                break                 # 排序后可剪枝
            path.append(candidates[i])
            backtrack(i, remain - candidates[i])   # 仍从 i，可重复用
            path.pop()
    backtrack(0, target)
    return res
```

**复杂度**：时间 O(指数级)，空间 O(target)。

**最 Pythonic 写法**：用生成器递归，`yield` 出每个合法组合，免去显式的 `path` 回溯。

```python
def combinationSum(candidates: list[int], target: int) -> list[list[int]]:
    candidates.sort()
    def dfs(start, remain):
        if remain == 0:
            yield []
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remain:
                break
            for rest in dfs(i, remain - candidates[i]):
                yield [candidates[i], *rest]
    return list(dfs(0, target))
```

## 59. 括号生成（Generate Parentheses，LC 22，Medium）

**题意**：生成 `n` 对括号的所有合法组合。

**考点**：回溯剪枝（右括号数不能超过左括号数，左不超过 `n`）。

**思路**：维护已用左右括号数，按约束放置 `(` 或 `)`。

```python
def generateParenthesis(n: int) -> list[str]:
    res = []
    path = []
    def backtrack(open_n, close_n):
        if len(path) == 2 * n:
            res.append(''.join(path))
            return
        if open_n < n:               # 还能放左括号
            path.append('(')
            backtrack(open_n + 1, close_n)
            path.pop()
        if close_n < open_n:         # 右不超过左才合法
            path.append(')')
            backtrack(open_n, close_n + 1)
            path.pop()
    backtrack(0, 0)
    return res
```

**复杂度**：时间 O(卡特兰数)，空间 O(n)。

**最 Pythonic 写法**：用生成器递归，直接拼接字符串传递路径，`yield from` 汇总结果。

```python
def generateParenthesis(n: int) -> list[str]:
    def gen(open_n, close_n, path):
        if len(path) == 2 * n:
            yield path
            return
        if open_n < n:
            yield from gen(open_n + 1, close_n, path + '(')
        if close_n < open_n:
            yield from gen(open_n, close_n + 1, path + ')')
    return list(gen(0, 0, ''))
```

## 60. 单词搜索（Word Search，LC 79，Medium）

**题意**：判断网格中是否存在一条上下左右相邻的路径拼出目标单词（同格不可重复用）。

**考点**：DFS 回溯 + 原地标记访问；剪枝（首字符匹配再进入）。

**思路**：从每个格子出发 DFS，匹配则标记后向四方向递归，回溯时还原。

```python
def exist(board: list[list[str]], word: str) -> bool:
    m, n = len(board), len(board[0])
    def dfs(i, j, k):
        if k == len(word):
            return True
        if not (0 <= i < m and 0 <= j < n) or board[i][j] != word[k]:
            return False
        tmp, board[i][j] = board[i][j], '#'      # 标记访问
        found = (dfs(i + 1, j, k + 1) or dfs(i - 1, j, k + 1) or
                 dfs(i, j + 1, k + 1) or dfs(i, j - 1, k + 1))
        board[i][j] = tmp                         # 回溯还原
        return found
    return any(dfs(i, j, 0) for i in range(m) for j in range(n))
```

**复杂度**：时间 O(m·n·4^L)，空间 O(L)。

**最 Pythonic 写法**：用方向元组 + `any` 探四个邻居，回溯时还原为原字符 `word[k]`。

```python
def exist(board: list[list[str]], word: str) -> bool:
    m, n = len(board), len(board[0])
    def dfs(i, j, k):
        if not (0 <= i < m and 0 <= j < n) or board[i][j] != word[k]:
            return False
        if k == len(word) - 1:
            return True
        board[i][j] = '#'
        found = any(dfs(i + di, j + dj, k + 1)
                    for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)))
        board[i][j] = word[k]
        return found
    return any(dfs(i, j, 0) for i in range(m) for j in range(n))
```

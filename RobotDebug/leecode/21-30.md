## 21. 搜索二维矩阵 II（Search a 2D Matrix II，LC 240，Medium）

**题意**：矩阵每行从左到右递增、每列从上到下递增，判断目标值是否存在。

**考点**：利用「行列双单调」特性，从右上角开始走 Z 字（abandon row/col）。

**思路**：从右上角出发：比目标大则左移（排除一列），比目标小则下移（排除一行）。

```python
def searchMatrix(matrix: list[list[int]], target: int) -> bool:
    if not matrix:
        return False
    i, j = 0, len(matrix[0]) - 1      # 右上角
    while i < len(matrix) and j >= 0:
        v = matrix[i][j]
        if v == target:
            return True
        elif v > target:
            j -= 1                    # 排除当前列
        else:
            i += 1                    # 排除当前行
    return False
```

**复杂度**：时间 O(m + n)，空间 O(1)。

**最 Pythonic 写法**：每行用 `bisect` 二分，配合海象运算符与 `any` 一行判定（O(m·logn)，略慢于 Z 字搜索但极简）。

```python
from bisect import bisect_left

def searchMatrix(matrix: list[list[int]], target: int) -> bool:
    return any(
        (i := bisect_left(row, target)) < len(row) and row[i] == target
        for row in matrix
    )
```

## 22. 相交链表（Intersection of Two Linked Lists，LC 160，Easy）

**题意**：找两条单链表的相交起始节点，不相交返回 `None`。

**考点**：双指针走「拼接路径」消除长度差；常考为什么会相遇。

**思路**：指针 `a` 走完 A 接着走 B，`b` 走完 B 接着走 A，两者走过的总长度相等，必在交点（或同时为 None）相遇。

```python
def getIntersectionNode(headA: ListNode, headB: ListNode) -> ListNode:
    a, b = headA, headB
    while a is not b:
        a = a.next if a else headB
        b = b.next if b else headA
    return a
```

**复杂度**：时间 O(m + n)，空间 O(1)。

**最 Pythonic 写法**：集合记下 A 的所有节点，再扫 B 遇到第一个在集合中的即交点（更直白，代价是 O(m) 额外空间）。

```python
def getIntersectionNode(headA: ListNode, headB: ListNode) -> ListNode:
    seen = set()
    while headA:
        seen.add(headA)
        headA = headA.next
    while headB:
        if headB in seen:
            return headB
        headB = headB.next
    return None
```

## 23. 反转链表（Reverse Linked List，LC 206，Easy）

**题意**：反转单链表。

**考点**：最基础链表操作；要求会迭代与递归两种写法。

**思路**：迭代维护 `prev`，逐个把 `cur.next` 指向 `prev`。

```python
def reverseList(head: ListNode) -> ListNode:
    prev = None
    cur = head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：用元组赋值一行完成「调指针 + 推进」，无需临时变量 `nxt`。

```python
def reverseList(head: ListNode) -> ListNode:
    prev = None
    while head:
        head.next, prev, head = prev, head, head.next
    return prev
```

## 24. 回文链表（Palindrome Linked List，LC 234，Easy）

**题意**：判断链表是否为回文，要求 O(1) 空间。

**考点**：快慢指针找中点 + 反转后半段 + 双向比较。

**思路**：慢快指针定位中点，反转后半部分，再从两端向中间比较。

```python
def isPalindrome(head: ListNode) -> bool:
    slow = fast = head
    while fast and fast.next:           # 找中点
        slow = slow.next
        fast = fast.next.next
    prev = None                         # 反转后半段
    while slow:
        slow.next, prev, slow = prev, slow, slow.next
    left, right = head, prev
    while right:                        # 比较
        if left.val != right.val:
            return False
        left, right = left.next, right.next
    return True
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：把值取进列表，直接与反转切片比较，代码最短（以 O(n) 空间换可读性，严格 O(1) 用上面的原地反转法）。

```python
def isPalindrome(head: ListNode) -> bool:
    vals = []
    while head:
        vals.append(head.val)
        head = head.next
    return vals == vals[::-1]
```

## 25. 环形链表（Linked List Cycle，LC 141，Easy）

**题意**：判断链表是否有环。

**考点**：Floyd 快慢指针；为什么必然相遇。

**思路**：快指针每次走两步、慢指针一步，有环则必相遇，无环则快指针先到尾部。

```python
def hasCycle(head: ListNode) -> bool:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：用集合记录走过的节点，再次遇到即有环，最直白（O(n) 空间，Floyd 快慢指针才是 O(1) 最优）。

```python
def hasCycle(head: ListNode) -> bool:
    seen = set()
    while head:
        if head in seen:
            return True
        seen.add(head)
        head = head.next
    return False
```

## 26. 环形链表 II（Linked List Cycle II，LC 142，Medium）

**题意**：返回环的入口节点，无环返回 `None`。

**考点**：Floyd 判圈的数学推导（相遇后一个指针回头，二者同速再相遇于入口）。

**思路**：先用快慢指针找相遇点；再让一个指针回到头部，两指针同速前进，再次相遇即环入口。

```python
def detectCycle(head: ListNode) -> ListNode:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:                # 相遇
            p = head
            while p is not slow:
                p = p.next
                slow = slow.next
            return p
    return None
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：同样用集合，第一个重复访问的节点就是环入口，免去 Floyd 的数学推导（代价 O(n) 空间）。

```python
def detectCycle(head: ListNode) -> ListNode:
    seen = set()
    while head:
        if head in seen:
            return head
        seen.add(head)
        head = head.next
    return None
```

## 27. 合并两个有序链表（Merge Two Sorted Lists，LC 21，Easy）

**题意**：合并两条升序链表。

**考点**：哨兵（dummy）节点简化头部处理；归并思想。

**思路**：用哨兵节点 + 尾指针，逐个比较接较小的节点，最后接上剩余部分。

```python
def mergeTwoLists(l1: ListNode, l2: ListNode) -> ListNode:
    dummy = tail = ListNode()
    while l1 and l2:
        if l1.val <= l2.val:
            tail.next, l1 = l1, l1.next
        else:
            tail.next, l2 = l2, l2.next
        tail = tail.next
    tail.next = l1 or l2
    return dummy.next
```

**复杂度**：时间 O(m + n)，空间 O(1)。

**最 Pythonic 写法**：递归合并，每次选较小的头节点接上「剩下部分的合并结果」，表达最简洁。

```python
def mergeTwoLists(l1: ListNode, l2: ListNode) -> ListNode:
    if not l1 or not l2:
        return l1 or l2
    if l1.val <= l2.val:
        l1.next = mergeTwoLists(l1.next, l2)
        return l1
    l2.next = mergeTwoLists(l1, l2.next)
    return l2
```

## 28. 两数相加（Add Two Numbers，LC 2，Medium）

**题意**：两个逆序存储的非负整数链表，逐位相加返回新链表。

**考点**：进位处理；不等长与最高位进位的收尾。

**思路**：同步遍历两链表，逐位求和带进位，新建结果节点；循环条件包含进位。

```python
def addTwoNumbers(l1: ListNode, l2: ListNode) -> ListNode:
    dummy = tail = ListNode()
    carry = 0
    while l1 or l2 or carry:
        s = carry
        if l1:
            s += l1.val
            l1 = l1.next
        if l2:
            s += l2.val
            l2 = l2.next
        carry, digit = divmod(s, 10)
        tail.next = ListNode(digit)
        tail = tail.next
    return dummy.next
```

**复杂度**：时间 O(max(m, n))，空间 O(max(m, n))。

**最 Pythonic 写法**：借助 Python 大整数，先把两链表还原成整数相加，再逆序写回链表（工程上进位法更稳妥）。

```python
def addTwoNumbers(l1: ListNode, l2: ListNode) -> ListNode:
    def to_int(node):
        n, place = 0, 1
        while node:
            n += node.val * place
            place *= 10
            node = node.next
        return n
    total = to_int(l1) + to_int(l2)
    dummy = tail = ListNode()
    for ch in str(total)[::-1]:          # 逆序写回
        tail.next = ListNode(int(ch))
        tail = tail.next
    return dummy.next
```

## 29. 删除链表的倒数第 N 个结点（Remove Nth Node From End，LC 19，Medium）

**题意**：删除链表倒数第 `n` 个节点并返回头。

**考点**：双指针拉开 `n` 间距一次遍历；哨兵节点处理删头。

**思路**：`fast` 先走 `n` 步，再 `fast/slow` 同步前进；`fast` 到尾时 `slow` 正好在待删节点前驱。

```python
def removeNthFromEnd(head: ListNode, n: int) -> ListNode:
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n):
        fast = fast.next
    while fast.next:
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next
    return dummy.next
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：先把节点收进列表，再用负下标 `nodes[-n - 1]` 直取待删节点的前驱（代价 O(n) 空间，胜在直观）。

```python
def removeNthFromEnd(head: ListNode, n: int) -> ListNode:
    dummy = ListNode(0, head)
    nodes = [dummy]
    while head:
        nodes.append(head)
        head = head.next
    nodes[-n - 1].next = nodes[-n - 1].next.next
    return dummy.next
```

## 30. 两两交换链表中的节点（Swap Nodes in Pairs，LC 24，Medium）

**题意**：两两相邻节点交换，不能只改值。

**考点**：指针操作的顺序；哨兵节点。

**思路**：用哨兵，每次处理一对节点，调整三处指针后推进前驱。

```python
def swapPairs(head: ListNode) -> ListNode:
    dummy = prev = ListNode(0, head)
    while prev.next and prev.next.next:
        a = prev.next
        b = a.next
        a.next = b.next      # a 接 b 的后继
        b.next = a           # b 指向 a
        prev.next = b        # 前驱接 b
        prev = a             # 推进到下一对前
    return dummy.next
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：递归处理：交换前两个节点，第一个节点接上「剩余部分两两交换的结果」。

```python
def swapPairs(head: ListNode) -> ListNode:
    if not head or not head.next:
        return head
    second = head.next
    head.next = swapPairs(second.next)
    second.next = head
    return second
```

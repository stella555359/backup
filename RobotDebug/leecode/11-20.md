## 11. 滑动窗口最大值（Sliding Window Maximum，LC 239，Hard）

**题意**：长度为 `k` 的窗口从左滑到右，求每个窗口的最大值。

**考点**：单调队列（双端队列）；为何不用堆（删除过期元素麻烦）。

**思路**：维护一个**递减**的双端队列，存下标。新元素入队前弹出队尾比它小的；队首过期（下标 < i-k+1）则弹出。队首即当前窗口最大值。

```python
from collections import deque

def maxSlidingWindow(nums: list[int], k: int) -> list[int]:
    dq = deque()          # 存下标，对应值单调递减
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()                      # 维持单调递减
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()                  # 弹出过期队首
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

**复杂度**：时间 O(n)，空间 O(k)。

**最 Pythonic 写法**：单调双端队列已是该题最优且最 Pythonic 的解，这里用 `dq[0] == i - k` 表达「队首过期」更直观。

```python
from collections import deque

def maxSlidingWindow(nums: list[int], k: int) -> list[int]:
    dq = deque()
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] == i - k:               # 队首过期
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

## 12. 最小覆盖子串（Minimum Window Substring，LC 76，Hard）

**题意**：在 `s` 中找最短子串，使其包含 `t` 的所有字符（含重复次数）。

**考点**：可变长滑动窗口 + 计数；用 `need` 计数和 `missing` 变量判断是否满足。

**思路**：右指针扩张并减少缺口，缺口为 0 时收缩左指针求最短，并尝试更新答案。

```python
from collections import Counter

def minWindow(s: str, t: str) -> str:
    need = Counter(t)
    missing = len(t)          # 还差多少字符
    left = 0
    best = (float('inf'), 0, 0)
    for right, ch in enumerate(s):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        while missing == 0:               # 窗口已覆盖 t
            if right - left + 1 < best[0]:
                best = (right - left + 1, left, right)
            need[s[left]] += 1
            if need[s[left]] > 0:
                missing += 1
            left += 1
    return "" if best[0] == float('inf') else s[best[1]:best[2] + 1]
```

**复杂度**：时间 O(n + m)，空间 O(字符集)。

**最 Pythonic 写法**：用「布尔当整数」`missing -= need[ch] > 0` 精简缺口维护，只用 `start/end` 两个下标记录答案。

```python
from collections import Counter

def minWindow(s: str, t: str) -> str:
    need = Counter(t)
    missing = len(t)
    left = start = 0
    end = float('inf')
    for right, ch in enumerate(s):
        missing -= need[ch] > 0
        need[ch] -= 1
        while missing == 0:
            if right - left < end - start:
                start, end = left, right
            need[s[left]] += 1
            missing += need[s[left]] > 0
            left += 1
    return "" if end == float('inf') else s[start:end + 1]
```

## 13. 最大子数组和（Maximum Subarray，LC 53，Medium）

**题意**：求具有最大和的连续子数组之和。

**考点**：Kadane 算法（DP）；面试可追问「输出子数组区间」「分治解法」。

**思路**：`cur` 表示以当前元素结尾的最大和：`cur = max(x, cur + x)`，全程取最大。

```python
def maxSubArray(nums: list[int]) -> int:
    cur = best = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)      # 要么接上前面，要么自己重开
        best = max(best, cur)
    return best
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：把 Kadane 的「以当前元素结尾的最大和」交给 `accumulate`，一行取全局最大。

```python
from itertools import accumulate

def maxSubArray(nums: list[int]) -> int:
    return max(accumulate(nums, lambda cur, x: max(cur + x, x)))
```

## 14. 合并区间（Merge Intervals，LC 56，Medium）

**题意**：合并所有重叠的区间。

**考点**：按起点排序后线性扫描；重叠判定 `当前起点 <= 结果末尾终点`。

**思路**：按左端点排序，逐个尝试与结果列表最后一个区间合并，否则新开。

```python
def merge(intervals: list[list[int]]) -> list[list[int]]:
    intervals.sort(key=lambda x: x[0])
    res = []
    for s, e in intervals:
        if res and s <= res[-1][1]:
            res[-1][1] = max(res[-1][1], e)   # 重叠则扩展右端
        else:
            res.append([s, e])
    return res
```

**复杂度**：时间 O(nlogn)，空间 O(n)。

**最 Pythonic 写法**：列表默认按首元素字典序比较，直接 `sorted(intervals)` 即可，省掉 `key`。

```python
def merge(intervals: list[list[int]]) -> list[list[int]]:
    res = []
    for s, e in sorted(intervals):
        if res and s <= res[-1][1]:
            res[-1][1] = max(res[-1][1], e)
        else:
            res.append([s, e])
    return res
```

## 15. 轮转数组（Rotate Array，LC 189，Medium）

**题意**：将数组向右轮转 `k` 步，要求原地、O(1) 额外空间。

**考点**：三次翻转技巧；`k %= n` 边界。

**思路**：整体翻转 → 翻转前 `k` 个 → 翻转后 `n-k` 个。

```python
def rotate(nums: list[int], k: int) -> None:
    n = len(nums)
    k %= n
    def reverse(i, j):
        while i < j:
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
            j -= 1
    reverse(0, n - 1)
    reverse(0, k - 1)
    reverse(k, n - 1)
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：用切片拼接一行完成，`nums[:]` 保证原地修改（k=0 时也成立）。

```python
def rotate(nums: list[int], k: int) -> None:
    k %= len(nums)
    nums[:] = nums[-k:] + nums[:-k]
```

## 16. 除自身以外数组的乘积（Product of Array Except Self，LC 238，Medium）

**题意**：返回数组 `answer`，`answer[i]` 等于除 `nums[i]` 外所有元素乘积，**不能用除法**，O(n)。

**考点**：前缀积 × 后缀积；不能用除法（有 0 时除法失效）。

**思路**：先用前缀积填入结果，再从右往左乘后缀积，复用输出数组省空间。

```python
def productExceptSelf(nums: list[int]) -> list[int]:
    n = len(nums)
    res = [1] * n
    for i in range(1, n):
        res[i] = res[i - 1] * nums[i - 1]    # 左侧乘积
    right = 1
    for i in range(n - 1, -1, -1):
        res[i] *= right                      # 乘右侧乘积
        right *= nums[i]
    return res
```

**复杂度**：时间 O(n)，空间 O(1)（不计输出）。

**最 Pythonic 写法**：用 `accumulate(mul, initial=1)` 分别算出前缀积与后缀积，再逐位相乘。

```python
from itertools import accumulate
from operator import mul

def productExceptSelf(nums: list[int]) -> list[int]:
    n = len(nums)
    pre = list(accumulate(nums, mul, initial=1))            # pre[i] = 前 i 个乘积
    suf = list(accumulate(reversed(nums), mul, initial=1))[::-1]
    return [pre[i] * suf[i + 1] for i in range(n)]
```

## 17. 缺失的第一个正数（First Missing Positive，LC 41，Hard）

**题意**：找出未出现的最小正整数，要求 O(n) 时间、O(1) 空间。

**考点**：原地哈希（把值 `v` 放到下标 `v-1`）；答案范围必在 `[1, n+1]`。

**思路**：把每个在 `[1,n]` 范围内的值交换到「它应在的位置」，再扫描第一个不匹配的下标。

```python
def firstMissingPositive(nums: list[int]) -> int:
    n = len(nums)
    for i in range(n):
        # 把 nums[i] 换到正确位置，直到无法继续
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            j = nums[i] - 1
            nums[i], nums[j] = nums[j], nums[i]
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：转成集合后用生成器 + `next` 取第一个缺失的正整数（以 O(n) 空间换极简表达）。

```python
def firstMissingPositive(nums: list[int]) -> int:
    s = set(nums)
    return next(i for i in range(1, len(nums) + 2) if i not in s)
```

## 18. 矩阵置零（Set Matrix Zeroes，LC 73，Medium）

**题意**：若元素为 0，则把其所在行和列全部置 0，原地完成。

**考点**：用首行/首列当标记位实现 O(1) 额外空间；先单独记录首行首列是否含 0。

**思路**：用第一行、第一列记录对应列/行是否需要清零，最后再处理首行首列本身。

```python
def setZeroes(matrix: list[list[int]]) -> None:
    m, n = len(matrix), len(matrix[0])
    first_row = any(matrix[0][j] == 0 for j in range(n))
    first_col = any(matrix[i][0] == 0 for i in range(m))
    for i in range(1, m):
        for j in range(1, n):
            if matrix[i][j] == 0:
                matrix[i][0] = matrix[0][j] = 0   # 打标记
    for i in range(1, m):
        for j in range(1, n):
            if matrix[i][0] == 0 or matrix[0][j] == 0:
                matrix[i][j] = 0
    if first_row:
        for j in range(n):
            matrix[0][j] = 0
    if first_col:
        for i in range(m):
            matrix[i][0] = 0
```

**复杂度**：时间 O(m·n)，空间 O(1)。

**最 Pythonic 写法**：用集合推导先记下含 0 的行号与列号，再统一置零，逻辑最清晰（O(m+n) 额外空间）。

```python
def setZeroes(matrix: list[list[int]]) -> None:
    m, n = len(matrix), len(matrix[0])
    zero_rows = {i for i in range(m) if 0 in matrix[i]}
    zero_cols = {j for j in range(n) if any(matrix[i][j] == 0 for i in range(m))}
    for i in range(m):
        for j in range(n):
            if i in zero_rows or j in zero_cols:
                matrix[i][j] = 0
```

## 19. 螺旋矩阵（Spiral Matrix，LC 54，Medium）

**题意**：按顺时针螺旋顺序返回矩阵所有元素。

**考点**：四个边界收缩；循环终止条件易错。

**思路**：维护 `top/bottom/left/right` 四条边界，按右→下→左→上方向遍历并收缩边界。

```python
def spiralOrder(matrix: list[list[int]]) -> list[int]:
    if not matrix:
        return []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    res = []
    while top <= bottom and left <= right:
        for j in range(left, right + 1):
            res.append(matrix[top][j])
        top += 1
        for i in range(top, bottom + 1):
            res.append(matrix[i][right])
        right -= 1
        if top <= bottom:
            for j in range(right, left - 1, -1):
                res.append(matrix[bottom][j])
            bottom -= 1
        if left <= right:
            for i in range(bottom, top - 1, -1):
                res.append(matrix[i][left])
            left += 1
    return res
```

**复杂度**：时间 O(m·n)，空间 O(1)（不计输出）。

**最 Pythonic 写法**：「取首行 + 逆时针旋转余下部分」反复进行，经典的优雅解法。

```python
def spiralOrder(matrix: list[list[int]]) -> list[int]:
    res = []
    while matrix:
        res += matrix.pop(0)                       # 取走首行
        matrix = [list(row) for row in zip(*matrix)][::-1]   # 余下部分逆时针旋转
    return res
```

## 20. 旋转图像（Rotate Image，LC 48，Medium）

**题意**：将 `n×n` 矩阵原地顺时针旋转 90°。

**考点**：转置 + 水平翻转的组合技巧；原地。

**思路**：先沿主对角线转置，再左右翻转每一行，等价于顺时针旋转 90°。

```python
def rotate(matrix: list[list[int]]) -> None:
    n = len(matrix)
    for i in range(n):                     # 转置
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:                     # 每行翻转
        row.reverse()
```

**复杂度**：时间 O(n²)，空间 O(1)。

**最 Pythonic 写法**：`zip(*matrix[::-1])` 先翻转行再转置，等价顺时针 90°，一行完成（`matrix[:]` 保持原地语义）。

```python
def rotate(matrix: list[list[int]]) -> None:
    matrix[:] = [list(row) for row in zip(*matrix[::-1])]
```

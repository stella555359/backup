## 61. 分割回文串（Palindrome Partitioning，LC 131，Medium）

**题意**：把字符串切分成若干子串，使每个子串都是回文，返回所有切法。

**考点**：回溯 + 回文判断；可用 DP 预处理回文表加速。

**思路**：从位置 `start` 起枚举切点，若 `s[start:i+1]` 回文则递归处理剩余部分。

```python
def partition(s: str) -> list[list[str]]:
    res = []
    path = []
    def is_pal(sub):
        return sub == sub[::-1]
    def backtrack(start):
        if start == len(s):
            res.append(path[:])
            return
        for i in range(start, len(s)):
            if is_pal(s[start:i + 1]):
                path.append(s[start:i + 1])
                backtrack(i + 1)
                path.pop()
    backtrack(0)
    return res
```

**复杂度**：时间 O(n·2ⁿ)，空间 O(n)。

**最 Pythonic 写法**：生成器递归，枚举切点，回文切片拼上剩余部分的划分。

```python
def partition(s: str) -> list[list[str]]:
    def dfs(start):
        if start == len(s):
            yield []
            return
        for end in range(start + 1, len(s) + 1):
            piece = s[start:end]
            if piece == piece[::-1]:
                for rest in dfs(end):
                    yield [piece, *rest]
    return list(dfs(0))
```

## 62. N 皇后（N-Queens，LC 51，Hard）

**题意**：在 `n×n` 棋盘放 `n` 个互不攻击的皇后，返回所有布局。

**考点**：回溯 + 三组冲突集合（列、主对角线、副对角线）O(1) 判冲突。

**思路**：逐行放置，用集合记录已占用的列与两条对角线；`row-col`、`row+col` 唯一标识对角线。

```python
def solveNQueens(n: int) -> list[list[str]]:
    res = []
    cols, diag1, diag2 = set(), set(), set()
    queens = []
    def backtrack(row):
        if row == n:
            res.append(['.' * c + 'Q' + '.' * (n - c - 1) for c in queens])
            return
        for col in range(n):
            if col in cols or (row - col) in diag1 or (row + col) in diag2:
                continue
            cols.add(col); diag1.add(row - col); diag2.add(row + col)
            queens.append(col)
            backtrack(row + 1)
            queens.pop()
            cols.remove(col); diag1.remove(row - col); diag2.remove(row + col)
    backtrack(0)
    return res
```

**复杂度**：时间 O(n!)，空间 O(n)。

**最 Pythonic 写法**：一个合法解本质是列号的一个排列，用 `permutations` 枚举，再靠两条对角线的集合大小过滤冲突。

```python
from itertools import permutations

def solveNQueens(n: int) -> list[list[str]]:
    boards = []
    for perm in permutations(range(n)):
        if n == len({i - perm[i] for i in range(n)}) == len({i + perm[i] for i in range(n)}):
            boards.append(['.' * c + 'Q' + '.' * (n - c - 1) for c in perm])
    return boards
```

## 63. 搜索插入位置（Search Insert Position，LC 35，Easy）

**题意**：升序数组中返回目标值的索引，不存在则返回应插入位置。

**考点**：二分查找「下界」模板（lower_bound）。

**思路**：标准二分，最终 `left` 即第一个 `>= target` 的位置。

```python
def searchInsert(nums: list[int], target: int) -> int:
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

**复杂度**：时间 O(logn)，空间 O(1)。

**最 Pythonic 写法**：下界二分就是 `bisect_left`，一行解决。

```python
from bisect import bisect_left

def searchInsert(nums: list[int], target: int) -> int:
    return bisect_left(nums, target)
```

## 64. 搜索二维矩阵（Search a 2D Matrix，LC 74，Medium）

**题意**：矩阵每行递增、且每行首元素大于上一行末元素，判断目标是否存在。

**考点**：把二维当一维做整体二分（坐标换算 `divmod`）。

**思路**：将下标 `mid` 映射为 `(mid // n, mid % n)`，对 `m*n` 个元素做一次二分。

```python
def searchMatrix(matrix: list[list[int]], target: int) -> bool:
    m, n = len(matrix), len(matrix[0])
    lo, hi = 0, m * n - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        v = matrix[mid // n][mid % n]
        if v == target:
            return True
        elif v < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return False
```

**复杂度**：时间 O(log(m·n))，空间 O(1)。

**最 Pythonic 写法**：先用首列 `bisect_right` 定位所在行，再在该行 `bisect_left` 定位列。

```python
from bisect import bisect_left, bisect_right

def searchMatrix(matrix: list[list[int]], target: int) -> bool:
    row = bisect_right([r[0] for r in matrix], target) - 1
    if row < 0:
        return False
    col = bisect_left(matrix[row], target)
    return col < len(matrix[row]) and matrix[row][col] == target
```

## 65. 在排序数组中查找元素的第一个和最后一个位置（Find First and Last Position，LC 34，Medium）

**题意**：返回目标值的起止下标，不存在返回 `[-1, -1]`。

**考点**：两次二分求左右边界；`bisect_left/right` 思想。

**思路**：分别用下界二分找第一个 `>= target` 和第一个 `> target`，组合得到区间。

```python
from bisect import bisect_left, bisect_right

def searchRange(nums: list[int], target: int) -> list[int]:
    left = bisect_left(nums, target)
    if left == len(nums) or nums[left] != target:
        return [-1, -1]
    right = bisect_right(nums, target) - 1
    return [left, right]
```

**复杂度**：时间 O(logn)，空间 O(1)。

**最 Pythonic 写法**：用 `lo < hi` 一步判定目标是否存在，避开单独取值比较。

```python
from bisect import bisect_left, bisect_right

def searchRange(nums: list[int], target: int) -> list[int]:
    lo = bisect_left(nums, target)
    hi = bisect_right(nums, target)
    return [lo, hi - 1] if lo < hi else [-1, -1]
```

## 66. 搜索旋转排序数组（Search in Rotated Sorted Array，LC 33，Medium）

**题意**：升序数组被旋转过，查找目标下标，要求 O(logn)。

**考点**：二分时判断哪半段有序，再决定收缩方向。

**思路**：每次判断左半 `[lo, mid]` 是否有序：有序则看目标是否落在其中，否则转向右半。

```python
def search(nums: list[int], target: int) -> int:
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:            # 左半有序
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                # 右半有序
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1
```

**复杂度**：时间 O(logn)，空间 O(1)。

**最 Pythonic 写法**：拆成「找旋转点 + 逻辑下标二分」两段，边界更不易错。

```python
def search(nums: list[int], target: int) -> int:
    n = len(nums)
    lo, hi = 0, n - 1
    while lo < hi:                       # 先找旋转点（最小值下标）
        mid = (lo + hi) // 2
        if nums[mid] > nums[hi]:
            lo = mid + 1
        else:
            hi = mid
    pivot = lo
    lo, hi = 0, n - 1
    while lo <= hi:                      # 在「逻辑有序」坐标上二分
        mid = (lo + hi) // 2
        real = (mid + pivot) % n
        if nums[real] == target:
            return real
        if nums[real] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## 67. 寻找旋转排序数组中的最小值（Find Minimum in Rotated Sorted Array，LC 153，Medium）

**题意**：旋转后的升序数组（元素不重复），求最小值。

**考点**：二分时与「右端点」比较判断最小值在哪半。

**思路**：`nums[mid] > nums[hi]` 说明最小值在右半，否则在左半（含 mid）。

```python
def findMin(nums: list[int]) -> int:
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] > nums[hi]:
            lo = mid + 1            # 最小值在右半
        else:
            hi = mid                # 最小值在左半（含 mid）
    return nums[lo]
```

**复杂度**：时间 O(logn)，空间 O(1)。

**最 Pythonic 写法**：直接 `min(nums)` 最 Pythonic（O(n)）；若要求 O(log n) 仍用上面的二分。

```python
def findMin(nums: list[int]) -> int:
    return min(nums)
```

## 68. 寻找两个正序数组的中位数（Median of Two Sorted Arrays，LC 4，Hard）

**题意**：两个升序数组，求合并后的中位数，要求 O(log(m+n))。

**考点**：对「较短数组」二分切分，使左半元素个数固定且左半最大 ≤ 右半最小。

**思路**：在短数组上二分割点 `i`，长数组割点由总数推出 `j`，校验交叉边界并收缩。

```python
def findMedianSortedArrays(nums1: list[int], nums2: list[int]) -> float:
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    m, n = len(nums1), len(nums2)
    total_left = (m + n + 1) // 2
    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi) // 2
        j = total_left - i
        left1 = nums1[i - 1] if i > 0 else float('-inf')
        right1 = nums1[i] if i < m else float('inf')
        left2 = nums2[j - 1] if j > 0 else float('-inf')
        right2 = nums2[j] if j < n else float('inf')
        if left1 <= right2 and left2 <= right1:      # 找到正确切分
            if (m + n) % 2:
                return max(left1, left2)
            return (max(left1, left2) + min(right1, right2)) / 2
        elif left1 > right2:
            hi = i - 1
        else:
            lo = i + 1
    return 0.0
```

**复杂度**：时间 O(log(min(m, n)))，空间 O(1)。

**最 Pythonic 写法**：合并后交给 `statistics.median`，一行出结果（O((m+n)log(m+n))；要求对数级时仍用上面的二分切分法）。

```python
import statistics

def findMedianSortedArrays(nums1: list[int], nums2: list[int]) -> float:
    return statistics.median(nums1 + nums2)
```

## 69. 有效的括号（Valid Parentheses，LC 20，Easy）

**题意**：判断只含 `()[]{}` 的字符串括号是否正确匹配。

**考点**：栈的经典应用；映射表 + 提前失败判断。

**思路**：左括号入栈，右括号则检查栈顶是否匹配，结束时栈应为空。

```python
def isValid(s: str) -> bool:
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
        else:
            stack.append(ch)
    return not stack
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：反复消去成对括号直到不能再消，写法极短（最坏 O(n²)，栈法才是 O(n)）。

```python
def isValid(s: str) -> bool:
    while '()' in s or '[]' in s or '{}' in s:
        s = s.replace('()', '').replace('[]', '').replace('{}', '')
    return not s
```

## 70. 最小栈（Min Stack，LC 155，Medium）

**题意**：设计支持 `push/pop/top/getMin` 且 `getMin` 为 O(1) 的栈。

**考点**：辅助栈同步记录当前最小值；存「差值」也可省空间。

**思路**：每次入栈同步把「当前最小值」压入辅助栈，使 `getMin` O(1)。

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.mins = []            # 与主栈同步的最小值栈

    def push(self, val: int) -> None:
        self.stack.append(val)
        self.mins.append(val if not self.mins else min(val, self.mins[-1]))

    def pop(self) -> None:
        self.stack.pop()
        self.mins.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.mins[-1]
```

**复杂度**：各操作均 O(1)。

**最 Pythonic 写法**：只用一个栈，每个元素存 `(值, 到此为止的最小值)` 元组，免维护第二个栈。

```python
class MinStack:
    def __init__(self):
        self.stack = []          # (值, 到此为止的最小值)

    def push(self, val: int) -> None:
        cur_min = min(val, self.stack[-1][1]) if self.stack else val
        self.stack.append((val, cur_min))

    def pop(self) -> None:
        self.stack.pop()

    def top(self) -> int:
        return self.stack[-1][0]

    def getMin(self) -> int:
        return self.stack[-1][1]
```

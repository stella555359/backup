## 41. 二叉树的层序遍历（Binary Tree Level Order Traversal，LC 102，Medium）

**题意**：按层从上到下、每层从左到右返回节点值。

**考点**：BFS 队列；如何「按层切分」（记录每层节点数）。

**思路**：队列做 BFS，每轮先取当前队列长度作为本层大小，循环处理一层。

```python
from collections import deque

def levelOrder(root: TreeNode) -> list[list[int]]:
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):       # 固定本层节点数
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：用列表推导逐层推进，本层值与下一层节点各一行，无需 `deque`。

```python
def levelOrder(root: TreeNode) -> list[list[int]]:
    res = []
    level = [root] if root else []
    while level:
        res.append([node.val for node in level])
        level = [kid for node in level for kid in (node.left, node.right) if kid]
    return res
```

## 42. 将有序数组转换为二叉搜索树（Convert Sorted Array to BST，LC 108，Easy）

**题意**：把升序数组转成一棵高度平衡的 BST。

**考点**：取中点作根可保证平衡；分治递归。

**思路**：每次取区间中点作根，左右子区间递归构建。

```python
def sortedArrayToBST(nums: list[int]) -> TreeNode:
    def build(lo, hi):
        if lo > hi:
            return None
        mid = (lo + hi) // 2
        node = TreeNode(nums[mid])
        node.left = build(lo, mid - 1)
        node.right = build(mid + 1, hi)
        return node
    return build(0, len(nums) - 1)
```

**复杂度**：时间 O(n)，空间 O(logn)。

**最 Pythonic 写法**：直接用切片递归，取中点作根、左右切片递归建树，免去下标管理（代价是切片的 O(n) 额外空间）。

```python
def sortedArrayToBST(nums: list[int]) -> TreeNode:
    if not nums:
        return None
    mid = len(nums) // 2
    root = TreeNode(nums[mid])
    root.left = sortedArrayToBST(nums[:mid])
    root.right = sortedArrayToBST(nums[mid + 1:])
    return root
```

## 43. 验证二叉搜索树（Validate Binary Search Tree，LC 98，Medium）

**题意**：判断是否为合法 BST（左子树全小于根、右子树全大于根）。

**考点**：易错点是「只比较父子」——必须用上下界约束整棵子树；或用中序递增判断。

**思路**：递归传入合法区间 `(low, high)`，节点值必须严格落在区间内。

```python
def isValidBST(root: TreeNode) -> bool:
    def valid(node, low, high):
        if not node:
            return True
        if not (low < node.val < high):
            return False
        return valid(node.left, low, node.val) and \
               valid(node.right, node.val, high)
    return valid(root, float('-inf'), float('inf'))
```

**复杂度**：时间 O(n)，空间 O(h)。

**最 Pythonic 写法**：用 `yield from` 生成器做中序遍历，再检查序列是否严格递增。

```python
def isValidBST(root: TreeNode) -> bool:
    def inorder(node):
        if node:
            yield from inorder(node.left)
            yield node.val
            yield from inorder(node.right)
    vals = list(inorder(root))
    return all(a < b for a, b in zip(vals, vals[1:]))
```

## 44. 二叉搜索树中第 K 小的元素（Kth Smallest Element in a BST，LC 230，Medium）

**题意**：返回 BST 中第 `k` 小的元素。

**考点**：BST 中序遍历即升序；可中途剪枝提前返回。

**思路**：中序遍历计数，到第 `k` 个即返回。

```python
def kthSmallest(root: TreeNode, k: int) -> int:
    stack = []
    cur = root
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        k -= 1
        if k == 0:
            return cur.val
        cur = cur.right
```

**复杂度**：时间 O(h + k)，空间 O(h)。

**最 Pythonic 写法**：中序生成器配合 `islice` 懒取第 k 个，天然支持中途停止。

```python
from itertools import islice

def kthSmallest(root: TreeNode, k: int) -> int:
    def inorder(node):
        if node:
            yield from inorder(node.left)
            yield node.val
            yield from inorder(node.right)
    return next(islice(inorder(root), k - 1, None))
```

## 45. 二叉树的右视图（Binary Tree Right Side View，LC 199，Medium）

**题意**：从右侧看，返回每层最右侧可见的节点值。

**考点**：BFS 取每层最后一个；或 DFS「先右后左」每层首次到达。

**思路**：层序遍历，记录每层最后一个节点值。

```python
from collections import deque

def rightSideView(root: TreeNode) -> list[int]:
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        n = len(q)
        for i in range(n):
            node = q.popleft()
            if i == n - 1:            # 本层最后一个
                res.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：同样用列表推导逐层推进，每层取最后一个 `level[-1]` 即右视图。

```python
def rightSideView(root: TreeNode) -> list[int]:
    res = []
    level = [root] if root else []
    while level:
        res.append(level[-1].val)
        level = [kid for node in level for kid in (node.left, node.right) if kid]
    return res
```

## 46. 二叉树展开为链表（Flatten Binary Tree to Linked List，LC 114，Medium）

**题意**：把二叉树按前序展开为只用右指针的「链表」，原地。

**考点**：前驱节点法实现 O(1) 额外空间；或后序反向连接。

**思路**：对每个有左子树的节点，找其左子树最右节点（前驱），把右子树挂到前驱后面，再把左子树移到右边。

```python
def flatten(root: TreeNode) -> None:
    cur = root
    while cur:
        if cur.left:
            pre = cur.left
            while pre.right:          # 找左子树最右节点
                pre = pre.right
            pre.right = cur.right     # 原右子树挂到前驱后
            cur.right = cur.left
            cur.left = None
        cur = cur.right
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：递归返回「展开后的尾节点」，把左子树接到节点与右子树之间，表达更清晰。

```python
def flatten(root: TreeNode) -> None:
    def dfs(node):
        if not node:
            return None
        left_tail = dfs(node.left)
        right_tail = dfs(node.right)
        if left_tail:
            left_tail.right = node.right
            node.right = node.left
            node.left = None
        return right_tail or left_tail or node
    dfs(root)
```

## 47. 从前序与中序遍历序列构造二叉树（Construct Binary Tree，LC 105，Medium）

**题意**：由前序和中序遍历重建二叉树（值唯一）。

**考点**：前序首元素是根；中序中根的位置划分左右子树；用哈希表加速定位。

**思路**：前序第一个为根，在中序里定位根从而知道左子树大小，递归构造。

```python
def buildTree(preorder: list[int], inorder: list[int]) -> TreeNode:
    idx = {v: i for i, v in enumerate(inorder)}   # 值 -> 中序下标
    self_pre = iter(preorder)
    def build(lo, hi):
        if lo > hi:
            return None
        root_val = next(self_pre)
        root = TreeNode(root_val)
        mid = idx[root_val]
        root.left = build(lo, mid - 1)
        root.right = build(mid + 1, hi)
        return root
    return build(0, len(inorder) - 1)
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：用切片递归：前序首个为根，`inorder.index` 定位后切出左右子数组，代码最短（代价是 O(n²) 最坏，哈希+迭代器法才是 O(n)）。

```python
def buildTree(preorder: list[int], inorder: list[int]) -> TreeNode:
    if not preorder:
        return None
    root = TreeNode(preorder[0])
    mid = inorder.index(preorder[0])
    root.left = buildTree(preorder[1:mid + 1], inorder[:mid])
    root.right = buildTree(preorder[mid + 1:], inorder[mid + 1:])
    return root
```

## 48. 路径总和 III（Path Sum III，LC 437，Medium）

**题意**：求「值之和等于目标」的路径数目，路径需向下但不必从根开始或到叶结束。

**考点**：前缀和 + 哈希（和第 10 题同源），把树上路径转成前缀和差。

**思路**：DFS 维护根到当前节点的前缀和，查 `当前前缀和 - target` 出现次数；回溯时撤销计数。

```python
from collections import defaultdict

def pathSum(root: TreeNode, targetSum: int) -> int:
    prefix = defaultdict(int)
    prefix[0] = 1
    def dfs(node, cur):
        if not node:
            return 0
        cur += node.val
        cnt = prefix[cur - targetSum]    # 以 node 结尾的合法路径数
        prefix[cur] += 1
        cnt += dfs(node.left, cur) + dfs(node.right, cur)
        prefix[cur] -= 1                 # 回溯
        return cnt
    return dfs(root, 0)
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：用 `Counter` 代替 `defaultdict` 记前缀和频次，语义更贴切（思路与上面一致）。

```python
from collections import Counter

def pathSum(root: TreeNode, targetSum: int) -> int:
    prefix = Counter({0: 1})
    def dfs(node, cur):
        if not node:
            return 0
        cur += node.val
        cnt = prefix[cur - targetSum]
        prefix[cur] += 1
        cnt += dfs(node.left, cur) + dfs(node.right, cur)
        prefix[cur] -= 1                 # 回溯
        return cnt
    return dfs(root, 0)
```

## 49. 二叉树的最近公共祖先（Lowest Common Ancestor，LC 236，Medium）

**题意**：找两个节点 `p`、`q` 的最近公共祖先。

**考点**：后序递归；理解「左右子树各找到一个」即当前为 LCA。

**思路**：递归到底，若当前节点是 `p`/`q` 或左右子树分别返回非空，则当前节点即 LCA。

```python
def lowestCommonAncestor(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
    if not root or root is p or root is q:
        return root
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left and right:        # 两侧各一个，当前即 LCA
        return root
    return left or right
```

**复杂度**：时间 O(n)，空间 O(h)。

**最 Pythonic 写法**：用 `root in (None, p, q)` 和 `left or right` 把递归压成最精简的形态。

```python
def lowestCommonAncestor(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
    if root in (None, p, q):
        return root
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    return root if left and right else left or right
```

## 50. 二叉树中的最大路径和（Binary Tree Maximum Path Sum，LC 124，Hard）

**题意**：路径为任意节点序列（父子相连，不必过根），求最大节点值之和。

**考点**：后序回传「单边最大贡献」，与第 40 题直径同构；负贡献需置 0。

**思路**：DFS 返回该节点向下的最大单边贡献（负则取 0），同时用「左贡献 + 右贡献 + 自身」更新全局最大。

```python
def maxPathSum(root: TreeNode) -> int:
    best = float('-inf')
    def gain(node):
        nonlocal best
        if not node:
            return 0
        left = max(gain(node.left), 0)    # 负贡献丢弃
        right = max(gain(node.right), 0)
        best = max(best, node.val + left + right)
        return node.val + max(left, right)
    gain(root)
    return best
```

**复杂度**：时间 O(n)，空间 O(h)。

**最 Pythonic 写法**：后序回传 + `nonlocal` 本身已是该题最 Pythonic 的形态，这里把两个 `max(gain, 0)` 合并到一行。

```python
def maxPathSum(root: TreeNode) -> int:
    best = float('-inf')
    def gain(node):
        nonlocal best
        if not node:
            return 0
        left, right = max(gain(node.left), 0), max(gain(node.right), 0)
        best = max(best, node.val + left + right)
        return node.val + max(left, right)
    gain(root)
    return best
```

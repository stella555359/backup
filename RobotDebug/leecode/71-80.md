## 71. 字符串解码（Decode String，LC 394，Medium）

**题意**：把 `k[encoded]` 形式的编码串展开，如 `3[a2[c]]` → `accaccacc`。

**考点**：双栈（数字栈 + 字符串栈）处理嵌套；遇 `]` 回弹合并。

**思路**：遇数字累积倍数，遇 `[` 把当前串和倍数压栈，遇 `]` 弹出并重复拼接。

```python
def decodeString(s: str) -> str:
    num_stack, str_stack = [], []
    cur = ''
    num = 0
    for ch in s:
        if ch.isdigit():
            num = num * 10 + int(ch)
        elif ch == '[':
            num_stack.append(num)
            str_stack.append(cur)
            num, cur = 0, ''
        elif ch == ']':
            k = num_stack.pop()
            cur = str_stack.pop() + cur * k
        else:
            cur += ch
    return cur
```

**复杂度**：时间 O(输出长度)，空间 O(嵌套深度)。

**最 Pythonic 写法**：用正则反复展开最内层 `k[...]`（`[a-z]*` 保证只匹配不含括号的内层），直到无括号。

```python
import re

def decodeString(s: str) -> str:
    pattern = re.compile(r'(\d+)\[([a-z]*)\]')
    while '[' in s:
        s = pattern.sub(lambda m: int(m[1]) * m[2], s)
    return s
```

## 72. 每日温度（Daily Temperatures，LC 739，Medium）

**题意**：对每天求「还要等几天才会更暖和」，没有则为 0。

**考点**：单调递减栈（存下标），求「下一个更大元素」。

**思路**：栈中保持温度递减的下标，遇到更高温就弹栈结算间隔天数。

```python
def dailyTemperatures(temperatures: list[int]) -> list[int]:
    res = [0] * len(temperatures)
    stack = []          # 存下标，对应温度递减
    for i, t in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < t:
            j = stack.pop()
            res[j] = i - j
        stack.append(i)
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：栈里直接存 `(下标, 温度)` 元组，免去反复 `temperatures[stack[-1]]` 二次索引，可读性更好。

```python
def dailyTemperatures(temperatures: list[int]) -> list[int]:
    res = [0] * len(temperatures)
    stack = []                    # 存 (下标, 温度)，温度递减
    for i, t in enumerate(temperatures):
        while stack and stack[-1][1] < t:
            j, _ = stack.pop()
            res[j] = i - j
        stack.append((i, t))
    return res
```

## 73. 柱状图中最大的矩形（Largest Rectangle in Histogram，LC 84，Hard）

**题意**：每根柱宽为 1、高为 `heights[i]`，求能勾勒的最大矩形面积。

**考点**：单调递增栈求每根柱左右第一个更矮柱；哨兵简化边界。

**思路**：维护递增栈，遇到更矮柱时弹栈，以弹出柱高为高、左右边界算宽度更新面积。首尾加 0 作哨兵。

```python
def largestRectangleArea(heights: list[int]) -> int:
    heights = [0] + heights + [0]      # 前后哨兵
    stack = [0]
    best = 0
    for i in range(1, len(heights)):
        while heights[i] < heights[stack[-1]]:
            h = heights[stack.pop()]
            w = i - stack[-1] - 1      # 左右边界之间的宽度
            best = max(best, h * w)
        stack.append(i)
    return best
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：只在末尾拼一个 `0` 哨兵触发清算，栈空时宽度取 `i`，可读性更好。

```python
def largestRectangleArea(heights: list[int]) -> int:
    stack = []          # 存下标，对应高度递增
    best = 0
    for i, h in enumerate(heights + [0]):     # 末尾哨兵
        while stack and heights[stack[-1]] > h:
            top = stack.pop()
            width = i - stack[-1] - 1 if stack else i
            best = max(best, heights[top] * width)
        stack.append(i)
    return best
```

## 74. 数组中的第 K 个最大元素（Kth Largest Element，LC 215，Medium）

**题意**：返回未排序数组中第 `k` 大的元素，期望优于全排序。

**考点**：小顶堆维护 Top K（O(nlogk)），或快速选择（平均 O(n)）。

**思路**：维护大小为 `k` 的小顶堆，堆顶即第 `k` 大。

```python
import heapq

def findKthLargest(nums: list[int], k: int) -> int:
    heap = nums[:k]
    heapq.heapify(heap)
    for x in nums[k:]:
        if x > heap[0]:
            heapq.heapreplace(heap, x)   # 弹出最小并压入 x
    return heap[0]
```

**复杂度**：时间 O(nlogk)，空间 O(k)。

**最 Pythonic 写法**：`heapq.nlargest` 取前 k 大，末位即第 k 大，一行解决。

```python
import heapq

def findKthLargest(nums: list[int], k: int) -> int:
    return heapq.nlargest(k, nums)[-1]
```

## 75. 前 K 个高频元素（Top K Frequent Elements，LC 347，Medium）

**题意**：返回出现频率前 `k` 高的元素。

**考点**：哈希计数 + 堆；也可桶排序做到 O(n)。

**思路**：统计频次后用 `heapq.nlargest` 取前 `k`。

```python
from collections import Counter
import heapq

def topKFrequent(nums: list[int], k: int) -> list[int]:
    cnt = Counter(nums)
    return heapq.nlargest(k, cnt.keys(), key=cnt.get)
```

**复杂度**：时间 O(nlogk)，空间 O(n)。

**最 Pythonic 写法**：`Counter.most_common(k)` 直接返回频次最高的 k 个，最简洁。

```python
from collections import Counter

def topKFrequent(nums: list[int], k: int) -> list[int]:
    return [x for x, _ in Counter(nums).most_common(k)]
```

## 76. 数据流的中位数（Find Median from Data Stream，LC 295，Hard）

**题意**：动态加入数字并随时返回当前中位数。

**考点**：对顶双堆（大顶堆存较小一半、小顶堆存较大一半），保持size差 ≤ 1。

**思路**：新数先入大顶堆再把堆顶转给小顶堆，若小顶堆更大则回流，保证平衡。

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.small = []     # 大顶堆（存负值），较小的一半
        self.large = []     # 小顶堆，较大的一半

    def addNum(self, num: int) -> None:
        heapq.heappush(self.small, -num)
        heapq.heappush(self.large, -heapq.heappop(self.small))
        if len(self.large) > len(self.small):
            heapq.heappush(self.small, -heapq.heappop(self.large))

    def findMedian(self) -> float:
        if len(self.small) > len(self.large):
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2
```

**复杂度**：`addNum` O(logn)，`findMedian` O(1)。

**最 Pythonic 写法**：用 `bisect.insort` 维护一个有序列表，中位数直取中间下标（`addNum` 退化到 O(n)，要求高吞吐仍用对顶双堆）。

```python
import bisect

class MedianFinder:
    def __init__(self):
        self.nums = []

    def addNum(self, num: int) -> None:
        bisect.insort(self.nums, num)

    def findMedian(self) -> float:
        n = len(self.nums)
        mid = n // 2
        if n % 2:
            return self.nums[mid]
        return (self.nums[mid - 1] + self.nums[mid]) / 2
```

## 77. 买卖股票的最佳时机（Best Time to Buy and Sell Stock，LC 121，Easy）

**题意**：只能买卖一次，求最大利润。

**考点**：一次遍历维护「历史最低价」；DP 思想的雏形。

**思路**：遍历时记录最低买入价，用当前价减最低价更新最大利润。

```python
def maxProfit(prices: list[int]) -> int:
    min_price = float('inf')
    best = 0
    for p in prices:
        min_price = min(min_price, p)
        best = max(best, p - min_price)
    return best
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：`accumulate(prices, min)` 生成「到目前为止的最低价」，与当前价逐一作差取最大。

```python
from itertools import accumulate

def maxProfit(prices: list[int]) -> int:
    return max((p - low for p, low in zip(prices, accumulate(prices, min))), default=0)
```

## 78. 跳跃游戏（Jump Game，LC 55，Medium）

**题意**：每个位置的值表示最大跳跃步数，判断能否到达最后一个下标。

**考点**：贪心维护「能到达的最远位置」。

**思路**：遍历时若当前下标超过可达最远则失败；否则不断更新最远可达。

```python
def canJump(nums: list[int]) -> bool:
    reach = 0
    for i, step in enumerate(nums):
        if i > reach:
            return False
        reach = max(reach, i + step)
    return True
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：从终点反向贪心，不断把「能跳到当前 goal」的位置当作新 goal，最后看 goal 是否回到 0。

```python
def canJump(nums: list[int]) -> bool:
    goal = len(nums) - 1
    for i in range(len(nums) - 1, -1, -1):
        if i + nums[i] >= goal:
            goal = i
    return goal == 0
```

## 79. 跳跃游戏 II（Jump Game II，LC 45，Medium）

**题意**：保证可达终点，求到达最后一个下标的最少跳数。

**考点**：贪心「区间扩张」——隐式 BFS 分层；到达当前边界时步数加一。

**思路**：维护当前跳能到的边界 `cur_end` 与下一跳最远 `farthest`，到达边界即必须再跳一次。

```python
def jump(nums: list[int]) -> int:
    jumps = 0
    cur_end = 0
    farthest = 0
    for i in range(len(nums) - 1):
        farthest = max(farthest, i + nums[i])
        if i == cur_end:           # 到达当前跳的边界
            jumps += 1
            cur_end = farthest
    return jumps
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：显式的「逐层扩张」：每层用 `max` 求出下一层能到达的最远边界，跳数加一。

```python
def jump(nums: list[int]) -> int:
    jumps = left = right = 0
    while right < len(nums) - 1:
        farthest = max(i + nums[i] for i in range(left, right + 1))
        left, right = right + 1, farthest
        jumps += 1
    return jumps
```

## 80. 划分字母区间（Partition Labels，LC 763，Medium）

**题意**：把字符串划分成尽量多的片段，使同一字母只出现在一个片段中，返回各片段长度。

**考点**：贪心 + 记录每个字母最后出现位置；类似合并区间。

**思路**：先记录每个字母最后出现下标，遍历时把当前片段的右边界扩展到片段内字母的最远位置，到达则切分。

```python
def partitionLabels(s: str) -> list[int]:
    last = {ch: i for i, ch in enumerate(s)}
    res = []
    start = end = 0
    for i, ch in enumerate(s):
        end = max(end, last[ch])    # 当前片段必须覆盖到此
        if i == end:
            res.append(end - start + 1)
            start = i + 1
    return res
```

**复杂度**：时间 O(n)，空间 O(字符集)。

**最 Pythonic 写法**：「字典记最后位置 + 贪心扩边界」已是最 Pythonic 的形态；若追求更短，可用 `str.rindex` 现算最后位置免去字典（代价是 O(n²)，数据量大仍用上面的字典法）。

```python
def partitionLabels(s: str) -> list[int]:
    res = []
    start = end = 0
    for i, ch in enumerate(s):
        end = max(end, s.rindex(ch))    # 该字符最后出现位置
        if i == end:
            res.append(end - start + 1)
            start = i + 1
    return res
```

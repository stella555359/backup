## 通用数据结构定义

```python
# 链表节点
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 二叉树节点
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

## 高频面试套路速查

- **哈希表**：用空间换时间，把「查找是否存在 / 出现次数」降到 O(1)。
- **双指针**：有序数组求和、原地移动、对撞收缩。
- **滑动窗口**：连续子串/子数组的最值或计数，右扩左缩。
- **前缀和 + 哈希**：子数组和相关问题（和为 K、整除等）。
- **单调栈 / 单调队列**：下一个更大元素、窗口最值、柱状图。
- **DFS / BFS**：树与图的遍历、连通块、最短路（无权图）。
- **回溯**：排列、组合、子集、棋盘类，注意剪枝与去重。
- **二分查找**：有序/旋转数组定位，注意边界与开闭区间。
- **动态规划**：定义状态 → 写转移方程 → 确定初始值与遍历顺序 → 优化空间。
- **堆**：Top K、动态求中位数（双堆）。

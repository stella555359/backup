## 31. K 个一组翻转链表（Reverse Nodes in k-Group，LC 25，Hard）

**题意**：每 `k` 个节点一组进行翻转，不足 `k` 个保持原序。

**考点**：链表翻转的工程化；先数够 `k` 个再翻转，注意组间衔接。

**思路**：用哨兵；每组先检查是否够 `k` 个，够则翻转该段并把前驱接到新头、旧头接到下一段。

```python
def reverseKGroup(head: ListNode, k: int) -> ListNode:
    dummy = group_prev = ListNode(0, head)
    while True:
        kth = group_prev                 # 找本组第 k 个节点
        for _ in range(k):
            kth = kth.next
            if not kth:
                return dummy.next
        group_next = kth.next
        prev, cur = group_next, group_prev.next
        while cur is not group_next:     # 翻转本组
            cur.next, prev, cur = prev, cur, cur.next
        new_tail = group_prev.next       # 原组头变组尾
        group_prev.next = kth
        group_prev = new_tail
```

**复杂度**：时间 O(n)，空间 O(1)。

**最 Pythonic 写法**：递归：先数够 k 个，不够则原样返回；否则先递归处理后续组，再用元组赋值翻转本组。

```python
def reverseKGroup(head: ListNode, k: int) -> ListNode:
    node = head
    for _ in range(k):
        if not node:
            return head            # 不足 k 个，保持原序
        node = node.next
    prev = reverseKGroup(node, k)   # 递归处理后续组
    cur = head
    for _ in range(k):
        cur.next, prev, cur = prev, cur, cur.next
    return prev
```

## 32. 随机链表的复制（Copy List with Random Pointer，LC 138，Medium）

**题意**：链表每个节点除 `next` 外还有 `random` 指针，深拷贝整个链表。

**考点**：原节点 → 新节点的映射；哈希表法 vs 交织节点的 O(1) 空间法。

**思路**：哈希表 `old → new`，第一遍建节点，第二遍接好 `next` 和 `random`。

```python
class Node:
    def __init__(self, x, next=None, random=None):
        self.val = x
        self.next = next
        self.random = random

def copyRandomList(head: 'Node') -> 'Node':
    if not head:
        return None
    mp = {}
    cur = head
    while cur:                       # 先克隆所有节点
        mp[cur] = Node(cur.val)
        cur = cur.next
    cur = head
    while cur:                       # 再接指针
        mp[cur].next = mp.get(cur.next)
        mp[cur].random = mp.get(cur.random)
        cur = cur.next
    return mp[head]
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：用 `defaultdict` 按需生成克隆节点，一遍扫描即可接好 `next` 与 `random`（`clones[None] = None` 处理空指针）。

```python
from collections import defaultdict

def copyRandomList(head: 'Node') -> 'Node':
    clones = defaultdict(lambda: Node(0))
    clones[None] = None
    cur = head
    while cur:
        clones[cur].val = cur.val
        clones[cur].next = clones[cur.next]
        clones[cur].random = clones[cur.random]
        cur = cur.next
    return clones[head]
```

## 33. 排序链表（Sort List，LC 148，Medium）

**题意**：在 O(nlogn) 时间内对链表排序。

**考点**：链表上的归并排序（自顶向下）；快慢指针找中点。

**思路**：快慢指针断成两半，递归排序后合并（复用第 27 题的合并逻辑）。

```python
def sortList(head: ListNode) -> ListNode:
    if not head or not head.next:
        return head
    slow, fast = head, head.next        # 找中点并断开
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    mid = slow.next
    slow.next = None
    left = sortList(head)
    right = sortList(mid)
    return merge(left, right)

def merge(l1, l2):
    dummy = tail = ListNode()
    while l1 and l2:
        if l1.val <= l2.val:
            tail.next, l1 = l1, l1.next
        else:
            tail.next, l2 = l2, l2.next
        tail = tail.next
    tail.next = l1 or l2
    return dummy.next
```

**复杂度**：时间 O(nlogn)，空间 O(logn)（递归栈）。

**最 Pythonic 写法**：取出全部值排序后回填节点，代码最简（代价是 O(n) 额外空间，非严格的「链表原地归并」）。

```python
def sortList(head: ListNode) -> ListNode:
    vals = []
    node = head
    while node:
        vals.append(node.val)
        node = node.next
    node = head
    for v in sorted(vals):
        node.val = v
        node = node.next
    return head
```

## 34. 合并 K 个升序链表（Merge k Sorted Lists，LC 23，Hard）

**题意**：合并 `k` 条升序链表为一条。

**考点**：最小堆（优先队列）；为避免比较 `ListNode` 报错，元组里加序号。

**思路**：把每条链表头入堆，每次弹出最小节点接入结果，再把其后继入堆。

```python
import heapq

def mergeKLists(lists: list[ListNode]) -> ListNode:
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))
    dummy = tail = ListNode()
    while heap:
        _, i, node = heapq.heappop(heap)
        tail.next = node
        tail = node
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next
```

**复杂度**：时间 O(N·logk)，空间 O(k)。

**最 Pythonic 写法**：把每条链表包成生成器，交给 `heapq.merge` 合并多个有序序列，再重建链表。

```python
import heapq

def mergeKLists(lists: list[ListNode]) -> ListNode:
    def gen(node):
        while node:
            yield node.val
            node = node.next
    dummy = tail = ListNode()
    for val in heapq.merge(*(gen(node) for node in lists)):
        tail.next = ListNode(val)
        tail = tail.next
    return dummy.next
```

## 35. LRU 缓存（LRU Cache，LC 146，Medium）

**题意**：实现支持 O(1) `get`/`put` 的 LRU 缓存，容量满时淘汰最久未用。

**考点**：哈希表 + 双向链表；Python 可用 `OrderedDict` 简化。

**思路**：`OrderedDict` 维护访问顺序，命中则移到末尾；超容量弹出最旧（队首）。

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)       # 标记为最近使用
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.cap:
            self.cache.popitem(last=False)  # 淘汰最久未用
```

**复杂度**：`get`/`put` 均摊 O(1)。

**最 Pythonic 写法**：甚至不需 `OrderedDict`——普通 `dict`（Python 3.7+）本身保持插入顺序，`pop` 后重插即「移到末尾」，`next(iter(...))` 取最旧键。

```python
class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.cache[key] = self.cache.pop(key)        # 重插到末尾
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        self.cache.pop(key, None)
        self.cache[key] = value
        if len(self.cache) > self.cap:
            del self.cache[next(iter(self.cache))]   # 删除最旧
```

## 36. 二叉树的中序遍历（Binary Tree Inorder Traversal，LC 94，Easy）

**题意**：返回中序遍历序列。

**考点**：递归与显式栈两种写法；中序对 BST 得到升序。

**思路**：递归最直观；迭代用栈模拟「一路向左入栈 → 出栈访问 → 转右」。

```python
def inorderTraversal(root: TreeNode) -> list[int]:
    res, stack = [], []
    cur = root
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        res.append(cur.val)
        cur = cur.right
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

**最 Pythonic 写法**：递归拼接「左子树 + 根 + 右子树」，与中序定义一一对应。

```python
def inorderTraversal(root: TreeNode) -> list[int]:
    if not root:
        return []
    return inorderTraversal(root.left) + [root.val] + inorderTraversal(root.right)
```

## 37. 二叉树的最大深度（Maximum Depth of Binary Tree，LC 104，Easy）

**题意**：求根到最远叶子的节点数。

**考点**：递归 DFS；也可 BFS 按层计数。

**思路**：深度 = `1 + max(左子树深度, 右子树深度)`。

```python
def maxDepth(root: TreeNode) -> int:
    if not root:
        return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))
```

**复杂度**：时间 O(n)，空间 O(h)。

**最 Pythonic 写法**：三元表达式压成一行递归。

```python
def maxDepth(root: TreeNode) -> int:
    return 1 + max(maxDepth(root.left), maxDepth(root.right)) if root else 0
```

## 38. 翻转二叉树（Invert Binary Tree，LC 226，Easy）

**题意**：左右子树整体镜像翻转。

**考点**：最简递归；曾是著名「面试梗」题。

**思路**：交换左右孩子并递归处理。

```python
def invertTree(root: TreeNode) -> TreeNode:
    if not root:
        return None
    root.left, root.right = invertTree(root.right), invertTree(root.left)
    return root
```

**复杂度**：时间 O(n)，空间 O(h)。

**最 Pythonic 写法**：用 `if root:` 护卫后一行交换，去掉显式的 `return None` 分支。

```python
def invertTree(root: TreeNode) -> TreeNode:
    if root:
        root.left, root.right = invertTree(root.right), invertTree(root.left)
    return root
```

## 39. 对称二叉树（Symmetric Tree，LC 101，Easy）

**题意**：判断二叉树是否轴对称。

**考点**：双指针同步遍历两棵镜像子树。

**思路**：递归比较 `(左.left, 右.right)` 与 `(左.right, 右.left)`。

```python
def isSymmetric(root: TreeNode) -> bool:
    def mirror(a, b):
        if not a and not b:
            return True
        if not a or not b or a.val != b.val:
            return False
        return mirror(a.left, b.right) and mirror(a.right, b.left)
    return mirror(root, root)
```

**复杂度**：时间 O(n)，空间 O(h)。

**最 Pythonic 写法**：用栈保存「镀像节点对」迭代比较，避免递归。

```python
def isSymmetric(root: TreeNode) -> bool:
    stack = [(root, root)]
    while stack:
        a, b = stack.pop()
        if not a and not b:
            continue
        if not a or not b or a.val != b.val:
            return False
        stack.append((a.left, b.right))
        stack.append((a.right, b.left))
    return True
```

## 40. 二叉树的直径（Diameter of Binary Tree，LC 543，Easy）

**题意**：任意两节点间最长路径的「边数」。

**考点**：后序遍历回传高度，顺带更新全局答案；直径不一定过根。

**思路**：DFS 返回子树高度，每个节点处用 `左高 + 右高` 更新最长路径。

```python
def diameterOfBinaryTree(root: TreeNode) -> int:
    best = 0
    def depth(node):
        nonlocal best
        if not node:
            return 0
        l = depth(node.left)
        r = depth(node.right)
        best = max(best, l + r)        # 经过该点的路径长度
        return 1 + max(l, r)
    depth(root)
    return best
```

**复杂度**：时间 O(n)，空间 O(h)。

**最 Pythonic 写法**：让 DFS 返回 `(高度, 直径)` 元组，用纯函数式传递避开 `nonlocal`。

```python
def diameterOfBinaryTree(root: TreeNode) -> int:
    def dfs(node):                    # 返回 (高度, 子树内最长路径)
        if not node:
            return 0, 0
        lh, ld = dfs(node.left)
        rh, rd = dfs(node.right)
        return 1 + max(lh, rh), max(ld, rd, lh + rh)
    return dfs(root)[1]
```

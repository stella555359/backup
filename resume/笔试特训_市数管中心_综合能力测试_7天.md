## 4. 背诵清单（A4 可抄）

### 4.1 时政（每个只记三句话）

**二十届三中全会改革主线**

1. 进一步全面深化改革，推进中国式现代化。  
2. 突出经济体制改革，推动高质量发展。  
3. 部署数字经济、全国统一大市场、安全发展等，答题落到「制度创新 + 落地见效」。

**数字中国 / 数字政府**

1. 数字技术与政务服务、社会治理、产业发展融合。  
2. 强调数据共享、一网通办、减少群众和企业重复跑。  
3. 安全与发展并重：数据要流通，也要分类分级、合法合规。

**浙江省数字化改革 / 营商环境**

1. 数字化改革是省域治理现代化的抓手。  
2. 营商环境看办事时间、材料份数、系统是否好用。  
3. 答题可写：整合入口、一次录入多方共享、为基层减负。

**杭州城市大脑与数字化改革**

1. 城市大脑用数据辅助交通、应急、民生服务等治理。  
2. 目标是让群众少跑腿、让治理看得见。  
3. 问题侧常见：系统多、数据不通、基层填表负担重。对策侧：统一入口、共享、闭环。

**公共数据与「可用不可见」**

1. 公共数据先登记、摸清目录，再谈授权与利用。  
2. 原始数据不出域、可用不可见，是授权运营常见表述。  
3. 笔试写「依法依规共享利用」，不写具体没做过的授权项目。

近两个月新闻：每看一篇只加 3 条到本页空白处，不要另开本。

### 4.2 法律（各 5 个考点，够客观题）

《网络安全法》

1. 网络运营者对网络安全负责，落实等级保护等义务。  
2. 关键信息基础设施重点保护。  
3. 违法信息、网络攻击等要监测、处置、报告。  
4. 真实身份、用户信息保护有要求。  
5. 违反规定可责令改正、罚款，情节严重可暂停相关业务。

《数据安全法》

1. 数据分类分级保护，重要数据重点保护。  
2. 数据处理活动（收集、存储、使用、加工、传输、提供、公开等）要合法正当。  
3. 重要数据出境、提供给境外要依法评估 / 许可（客观题认「依法」即可）。  
4. 数据安全事件要应急处置和报告。  
5. 国家 + 地方 + 行业监管，不是单靠企业自律。

《个人信息保护法》

1. 处理个人信息一般需取得同意，告知处理目的、方式、种类。  
2. 最小必要，不得过度收集。  
3. 敏感个人信息（生物识别、医疗健康、行踪等）要求更严。  
4. 个人有查阅、复制、更正、删除等权利。  
5. 违法行为可处高额罚款，答题选「告知同意 + 最小必要」。

客观题排除项：把「完全公开所有数据」「一律禁止共享」当成绝对正确。

## 5. 答题模板（考场直接套）

### 5.1 概括问题 / 原因（常见 150–250 字）

审题：概括什么（问题 / 原因 / 做法）、几则材料、字数。

结构：

```
主要问题（或原因）如下：
一、……不统一 / 不足 / 滞后。表现为……
二、……
三、……
```

加工公式：主体 + 问题词 + 具体表现（可带材料中的数字或例子，一句即可）。

不要：大段摘抄案例对话；不要自我发挥政策口号。

### 5.2 提出对策（常见 300–400 字）

身份：题干给什么身份就用什么（如区大数据局工作人员）。

结构：

```
针对上述问题，建议采取以下措施：
一、整合平台入口。由……牵头清理重复 APP / 填报系统，实现一次登录、分类办理。
二、打通数据共享。建立统一采集标准，一次录入、多方使用，减少重复填报。
三、压实责任闭环。明确承办单位、时限和反馈渠道，办理结果可查询、可追溯。
四、为基层减负。精简报表和考核指标，能共享的不再要基层重复报。
```

每条：谁来做 + 做什么 + 达到什么。可按材料措施改写，材料没有的只补 1 条常识级措施。

### 5.3 公文三件套

**通知**（下行，布置工作）

```

各处室，各区、县（市）……：

为……，现就有关事项通知如下：
一、工作目标

（一）……
（二）……
三、有关要求
请于×年×月×日前将……报送……

　　　　　　　　　　　　　　××单位
　　　　　　　　　　　　　　×年×月×日
```

**报告**（上行，反映情况）

```
关于……工作情况的报告
××：

现将……有关情况报告如下：
一、工作进展
……
二、存在问题
……
三、下一步安排
……

　　　　　　　　　　　　　　××单位
　　　　　　　　　　　　　　×年×月×日
```

**函**（平行文，协商）

```
××关于商请……的函
××单位：

……（事由）。
……（具体商请事项）。
请予支持为盼。

　　　　　　　　　　　　　　××单位
　　　　　　　　　　　　　　×年×月×日
```

注意：函不用「此致敬礼」；通知、报告一般也不用「此致敬礼」（那是信函习惯）。落款日期用汉字或阿拉伯数字按题干，常见「2026年9月27日」。

### 5.4 公文改错高频点

- 主送机关：通知可多主送；请示一般只主送一个上级
- 附件：正文中写「现将《××》印发给你们」或「附件：1.……」位置正确
- 「此致敬礼」误用在通知 / 报告上 → 删
- 漏写成文日期或公章位置
- 公开属性：涉密不用「主动公开」乱标
- 请示里夹带报告事项、一文多事
- 函的语气命令化（平行单位不能「必须于」）

### 5.5 短论述 / 小作文（约 800–1000 字）

```
标题（10 字左右，点出观点，如《以数据共享减基层负担》）

开头：材料现象 1–2 句 + 亮明总观点。

分论点一：……（制度 / 标准）。材料例子。
分论点二：……（平台 / 技术）。材料例子。
分论点三：……（落地 / 安全与减负）。材料例子。

结尾：回扣杭州数字化或「发展与安全并重」，3–4 句收住。
```

不要空喊「意义重大」。每个分论点至少有一句来自材料。

## 6. 三个可反复用的例子（各 4 行）

考场改成材料语言，不写公司名和产品名。

**例 1 城市大脑便民**

城市运行数据汇到同一平台后，交通、应急等可更快响应。  
关键不是多一个 APP，而是部门数据能对上。  
问题往往是入口分散、标准不一。  
对策：统一入口、统一标准、结果可查。

**例 2 一次录入多方使用**

同一事项在多个系统重复填，基层和群众都耗时。  
「一次录入、多方共享」能减少重复劳动。  
前提是目录清楚、权限清楚、质量可追。  
对策：清理重复系统 + 共享机制 + 禁止重复要数。

**例 3 内部平台减少重复劳动（用你的经历，写成通用表述）**

过去任务靠口头通知、结果靠人手对账，对不上就反复问。  
后来用统一页面提交任务、自动回收结果，和执行记录核对。  
指标异常能标出来，方便判断是环境问题还是系统问题。  
体会：平台要好用，先保证状态一致、责任可追溯；笔试写成「业务系统运行与数据核对」，不写具体工具名。

## 9. 和你背景的用法（提醒）

# 个人求职知识库

这个知识库用于把多年测试经验、当前自动化平台项目、AI 测试学习和面试表达整理成可持续复用的求职资产。

核心目标不是收藏资料，而是形成四类输出：

- 能写进简历的项目表达。
- 能在面试中讲清楚的案例和技术链路。
- 能证明能力的项目文档、Demo、截图、日志和代码路径。
- 能持续更新的学习记录和复盘机制。

## 目录导航

```text
career-knowledge-base/
  00-career-map/      个人定位、能力地图、证据链
  01-projects/        核心项目复盘包
  02-skills/          自动化测试、平台工程、AI 测试技能树
  03-ai-testing/      AI 测试学习路线和 Demo 计划
  04-interview-bank/  高频面试题、项目追问、STAR 案例
  05-job-targets/     岗位方向、简历版本和投递策略
  06-weekly-review/   两个月执行计划、周复盘、验证记录
  templates/          项目、知识点、面试回答模板
```

## 使用原则

1. 先写自己的经历，再补理论。
2. 每个知识点都要能回答“项目里怎么用过”。
3. 每个项目都要有“背景、方案、难点、结果、证据、追问”。
4. AI 相关内容重点体现测试视角：评估、验证、边界、数据质量、失败样例和人工复核。
5. 每周至少沉淀一次：新增知识、面试反馈、简历调整和下周计划。

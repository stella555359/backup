# AI 测试学习地图

## 第 1 层：基础概念

- LLM：大语言模型，负责生成回答。
- Embedding：把文本转成向量，用于语义检索。
- Vector Store：存储向量并支持相似度检索。
- RAG：先检索相关文档，再基于文档生成回答。
- Agent：模型可以拆解任务并调用工具。

## 第 2 层：测试对象

- Prompt。
- RAG 检索链路。
- LLM 回答。
- 工具调用。
- 多轮上下文。
- 权限和数据边界。

## 第 3 层：测试类型

- 功能正确性测试。
- 召回质量测试。
- 幻觉测试。
- 拒答测试。
- 安全和注入测试。
- 稳定性测试。
- 回归测试。

## 第 4 层：可展示产物

- 评测集。
- 失败样例库。
- 测试报告。
- prompt 版本记录。
- 引用来源检查记录。
- 人工复核结论。

## 每周学习安排

- 每周选择 2 个概念写知识点笔记。
- 每周新增 5 条 AI 测试问题到评测集。
- 每周总结 1 个失败样例。
- 每周把一个知识点转成面试回答。

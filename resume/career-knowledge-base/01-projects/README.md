# 01 Projects

这个目录沉淀可用于简历和面试的核心项目复盘。

## 项目清单

1. `5g-gnb-kpi-automation-platform.md`：主项目，重点体现自动化测试平台、FastAPI、React、Jenkins、runner、callback 和 AI assisted 工程实践。
2. `5g-gnb-system-test-automation.md`：长期 5G 系统测试和 Robot Framework 自动化建设经验。
3. `media-gateway-performance-stability.md`：早期性能测试、长稳测试和通信系统测试基础。
4. `regression-management-quality-kpi.md`：多 release 回归管理、Jenkins 每日回归、失败分析和质量 KPI。

## 使用方式

- 简历中只放 1-2 个主项目。
- 面试中根据岗位方向选择展开顺序。
- 每个项目都准备 3 分钟、8 分钟、15 分钟版本。
- 每个项目至少准备 5 个追问。

## 项目排序建议

自动化测试岗位：项目 2 -> 项目 1 -> 项目 4。

AI 测试 / 测试开发岗位：项目 1 -> AI Demo -> 项目 2。

平台测试 / DevOps 岗位：项目 1 -> 项目 4 -> 数据或 AI Demo。

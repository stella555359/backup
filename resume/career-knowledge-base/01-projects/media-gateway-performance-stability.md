# Media Gateway 性能测试与长稳测试

## 一句话定位

面向 3G 多媒体网关，负责兼容性测试、大话务量性能测试和 24 小时以上长稳测试，积累通信系统测试、容量验证和稳定性分析经验。

## 背景与痛点

Media Gateway 需要在运营商网络中承载大量语音和媒体业务，关注吞吐、呼叫成功率、资源占用、长时间运行稳定性和不同网络环境下的兼容性。测试不仅要验证功能正确，还要验证持续压力下是否出现资源泄漏、性能下降或异常恢复问题。

## 我的职责

- 执行面向 Vodafone、中国移动、中国联通等运营商场景的兼容性测试。
- 参与大话务量性能测试和长稳测试。
- 观察系统资源、告警、日志、业务成功率和异常恢复情况。
- 记录问题现象，配合开发定位并跟踪缺陷闭环。

## 核心流程

```text
测试目标确认
-> 话务模型和环境准备
-> 基线功能验证
-> 压力加载
-> 长时间稳定运行
-> 日志和指标采集
-> 异常分析
-> 测试报告输出
```

## 可迁移能力

- 性能测试不只看峰值，也要关注稳定性、恢复能力和趋势变化。
- 长稳测试需要提前定义观察指标、采样周期、失败判定和恢复策略。
- 通信系统问题往往需要结合业务现象、系统日志、资源指标和网络侧信息综合判断。

## 面试表达

早期 Media Gateway 项目让我建立了性能和稳定性测试的基础方法。比如在大话务量场景下，不能只看某一次测试是否通过，而要持续观察业务成功率、资源使用、日志告警和异常恢复。这个经验后来也迁移到了 5G 系统测试和自动化回归中，让我更关注测试结果背后的稳定性和可追踪性。

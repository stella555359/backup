## 2. 参考 PDF 的关键设计（白素刚版）

通过解析参考 PDF 的版面坐标/颜色得到以下设计要点：

- **证件照**：放在页面**右上角**，约 1 寸证件照比例（宽:高 ≈ 65:90）。
- **栏目标题**：整行**纯灰色色块**（灰值 `#A6A6A6`，即 RGB 166,166,166），标题文字左对齐嵌在灰条里。
- **分隔方式**：灰条本身就是分隔，**没有**额外的细横线（`---`）。
- **顶部**：居中的「个人简历」文档标题 +「基本信息」灰条 + 两列字段表格。

---

## 3. 最终采用的方案（当前 v1）

> 核心原则：**全部使用「行内样式（inline style）」**，不依赖 `<style>` 标签。

| 元素 | 实现方式 | 关键参数 |
| --- | --- | --- |
| 整篇容器 | 外层 `<div>` 包裹，靠继承统一正文字号 | `font-size:12px; line-height:1.45` |
| 文档标题「个人简历」 | 行内样式 `<p>` | 居中、`font-size:18px`、字间距 8px |
| 栏目标题 | 行内样式 `<h2>` 灰条 | 背景 `#A6A6A6`、`font-size:13px`、`print-color-adjust:exact` |
| 项目小标题 | 行内样式 `<h3>` | `font-size:12.5px`、左侧 4px 灰色竖条 |
| 基本信息 | `<div>` 弹性布局 + `<table>`，照片靠右 | 表格/单元格 `border:none`，照片 100×140 |
| 分隔线 | 全部删除 `---` | 由灰条充当分隔 |

---

## 4. 踩坑与经验教训（重要）

> 这些是反复返工的根因，后续修改务必牢记。

1. **`<style>` 标签会被 PDF 导出剥离**
   - 现象：转 PDF 后顶部出现一大段 CSS 文字、且「个人简历」不居中、灰条不生效。
   - 结论：当前导出链路**不认 `<style>` 块**。
   - 对策：**改用行内样式**（inline `style="..."`）。行内样式一定生效（照片能靠右就是证据）。统一字号则用「外层 div 包裹 + 继承」实现。

2. **表格默认会出现细横线**
   - 现象：基本信息区出现两条横线（3 行之间的行边框）。
   - 对策：在 `<table>` 和每个 `<td>` 上都写行内 `border:none`。

3. **灰条底色在 PDF 里可能丢失**
   - 对策：给灰条加 `-webkit-print-color-adjust:exact; print-color-adjust:exact;`；并确认扩展的 `printBackground=true`（yzane.markdown-pdf 默认即为 true）。

4. **PDF 左上角文件名 / 右上角日期 / 底部页码**
   - 来源：markdown-pdf 扩展的页眉页脚。
   - 对策：在 [.vscode/settings.json](.vscode/settings.json) 设 `"markdown-pdf.displayHeaderFooter": false`（已配置，作用于本文件夹）。

## 5. 导出 PDF 操作指南

- **扩展**：`yzane.markdown-pdf`（Markdown PDF）。
- **导出**：`Ctrl+Shift+P` → 输入 `Markdown PDF: Export (pdf)`；或编辑器右键 → Markdown PDF。
- **输出**：同目录、同名 `.pdf`。
- **相关配置**（[.vscode/settings.json](.vscode/settings.json)，作用于 resume 文件夹）：
  - `markdown-pdf.displayHeaderFooter: false` —— 去掉页眉(文件名/日期)与页脚(页码)。
  - 其余用扩展默认：A4、纵向、`printBackground:true`、页边距 上 1.5cm / 左右下 1cm。
- **预览**：打开 md 文件按 `Ctrl+Shift+V`（注意：预览与最终 PDF 可能有细微差异，以 PDF 为准）。

## 6. 页数控制（2 页）

- 当前正文字号 12px、行距 1.45，按内容量估算可落在 2 页。
- 若超出/想更紧凑，按顺序微调（改外层包裹 `<div>` 即可）：
  1. 正文字号 `font-size:12px` → `11.5px`
  2. 行距 `line-height:1.45` → `1.4`
  3. 灰条上下外边距 `margin:11px 0 6px 0` → 更小
- 若偏空想放大，反向调大字号即可。
